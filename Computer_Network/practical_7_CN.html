Computer Network

Practical No. 7

Aim: To configure computing devices such as PC, Laptop and Mobile for network communication and explore IP address, gateway, DNS and security options.

🖥️ Requirements

PC or Laptop, Mobile device, network connection and access to network configuration settings.

📌 Purpose

To understand basic network configuration options and observe their impact on network connectivity.

Introduction

A computing device requires appropriate network configuration to communicate over a network.

Important configuration parameters include IP address, subnet mask, default gateway, DNS settings and network security options.

Procedure

01

Open Network Settings

Open the network settings of the PC, laptop or mobile device.

02

Configure IP Address

Observe or configure the IP address and subnet settings as required by the network.

03

Configure Gateway

Observe the default gateway used by the device for communication outside the local network.

04

Configure DNS

Observe the DNS configuration used for resolving domain names.

05

Explore Security Settings

Observe available network security options such as Wi-Fi authentication and encryption settings.

06

Test Connectivity

Check whether the device can communicate with other network devices.

⚠️ Precautions

  • Use valid network configuration values.
  • Do not modify network settings without permission.
  • Do not share Wi-Fi passwords or security credentials.

✅ Result

Thus, network configuration options of computing devices were successfully studied and their impact on connectivity was observed.
