Practical No. 8

Aim: To establish TCP communication between two devices and observe the communication process.

🖥️ Requirements

Two computers or suitable network devices, network connection, TCP-enabled application or networking tool.

📌 Purpose

To understand reliable connection-oriented communication using TCP.

Introduction

TCP (Transmission Control Protocol) is a connection-oriented transport layer protocol. It provides reliable and ordered delivery of data between communicating devices.

TCP communication requires a connection between a client and server or between two endpoints before data is exchanged.

Procedure

01

Connect Devices

Connect two devices to the same network or suitable test network.

02

Configure Network

Configure valid IP addresses and verify basic connectivity.

03

Start TCP Service

Run a suitable TCP server application or network simulation service on one device.

04

Connect Client

Use the second device as a client and establish a TCP connection with the server.

05

Exchange Data

Send test data between the two devices through the established TCP connection.

06

Observe Communication

Observe the successful connection and data transfer using the selected network tool.

⚠️ Precautions

  • Use only authorized devices and networks for testing.
  • Configure valid IP addresses and communication parameters.
  • Do not perform testing on networks without permission.

✅ Result

Thus, TCP communication between two devices was successfully established and data exchange was observed.
