Practical No. 5

Aim: To make patch cords using different types of cables and connectors by performing crimping and splicing operations.

🖥️ Requirements

Network cable, RJ-45 connectors, crimping tool, cable stripper, cable tester and networking tools.

📌 Purpose

To understand the practical process of preparing network patch cords using appropriate cables and connectors.

Introduction

A patch cord is a short cable used to connect networking devices. Twisted-pair cables can be terminated with suitable connectors using a crimping tool.

Procedure

01

Measure Cable

Take the required length of networking cable.

02

Remove Outer Jacket

Carefully strip the outer jacket from both ends of the cable.

03

Arrange Wires

Arrange the individual wires according to the selected wiring standard.

04

Insert Connector

Insert the arranged wires properly into the connector.

05

Crimp the Connector

Use the crimping tool to securely attach the connector to the cable.

06

Prepare the Other End

Repeat the process for the other end of the patch cord.

⚠️ Precautions

  • Use the correct wiring arrangement at both ends.
  • Do not damage the internal conductors while stripping the cable.
  • Use the crimping tool carefully.

✅ Result

Thus, a network patch cord was successfully prepared using a networking cable and suitable connectors.
