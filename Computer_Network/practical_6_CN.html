Practical No. 6

Aim: To demonstrate different types of cable testers and use them to test patch cords prepared by students and standard network cables.

🖥️ Requirements

Cable tester, network patch cord, standard network cable, RJ-45 connectors and Computer Network laboratory equipment.

📌 Purpose

To check the continuity and correct wiring of network cables using appropriate cable testing equipment.

Introduction

A cable tester is a device used to check whether a network cable is properly connected and wired. It can help identify continuity problems, incorrect wiring and other cable faults.

Procedure

01

Collect Cable Tester

Obtain the available network cable tester from the laboratory.

02

Connect Patch Cord

Connect both ends of the prepared patch cord to the appropriate tester ports.

03

Start Testing

Switch on the tester and observe its indicators.

04

Observe Wiring

Check whether the conductors are detected in the expected sequence.

05

Test Standard Cable

Repeat the test using a standard professionally prepared cable.

06

Compare Results

Compare the test results of the student-prepared patch cord and standard cable.

⚠️ Precautions

  • Connect the cable correctly to the tester.
  • Do not apply excessive force to connectors.
  • Interpret tester indicators according to the tester's documentation.

✅ Result

Thus, different cable testing methods were demonstrated and the prepared and standard network cables were successfully tested.
