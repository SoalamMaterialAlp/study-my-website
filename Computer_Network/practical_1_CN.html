Computer Science and Engineering
Computer Network

Practical No. 1

Aim: To study any network simulation tool such as Wireshark, Cisco Packet Tracer, NS-2 or GNS3.

🖥️ Requirements

Personal Computer or Laptop, Network Simulation Tool, Internet connection and basic networking knowledge.

📌 Purpose

To understand the working environment and basic features of a network simulation or network analysis tool.

Introduction

A network simulation or analysis tool is used to study computer networks without requiring a complete physical network setup.

Tools such as Wireshark, Cisco Packet Tracer, NS-2 and GNS3 help students observe, design, simulate or analyze different networking concepts.

Procedure

01

Select a Network Tool

Select a suitable tool such as Cisco Packet Tracer or Wireshark.

02

Install the Tool

Install the selected networking tool on the computer.

03

Open the Application

Start the installed application and observe its main interface.

04

Explore Features

Explore devices, connections, packets, simulation controls and other available options.

05

Create or Analyze a Network

Create a simple network or capture and observe network traffic according to the selected tool.

⚠️ Precautions

  • Use the correct version of the selected network tool.
  • Do not change network settings unnecessarily.
  • Observe the simulation or captured packets carefully.

✅ Result

Thus, a network simulation/analysis tool was successfully studied and its basic features were observed.
