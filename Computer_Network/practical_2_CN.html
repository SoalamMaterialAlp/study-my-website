Practical No. 2

Aim: To understand and practically observe how data travels through OSI layers using a network tool.

🖥️ Requirements

Personal Computer or Laptop, Cisco Packet Tracer or Wireshark, network simulation tool and basic networking knowledge.

📌 Purpose

To understand the flow of data through different layers of the OSI reference model.

Introduction

The OSI model divides network communication into seven layers: Physical, Data Link, Network, Transport, Session, Presentation and Application.

When data is transmitted over a network, it passes through different layers where specific networking functions are performed.

Procedure

01

Open Network Tool

Open Cisco Packet Tracer, Wireshark or another suitable network tool.

02

Create Network

Create a simple network containing two end devices and a suitable connection.

03

Configure Devices

Assign appropriate network addresses to the devices.

04

Generate Data

Send data or a test packet from one device to another.

05

Observe OSI Layers

Use the simulation or packet-analysis feature to observe how the data moves through networking layers.

06

Analyze Communication

Observe the protocols and information associated with different layers.

⚠️ Precautions

  • Configure the devices correctly before sending data.
  • Use the correct simulation mode when available.
  • Observe each layer carefully during data transmission.

✅ Result

Thus, the flow of data through the OSI layers was successfully observed using a network tool.
