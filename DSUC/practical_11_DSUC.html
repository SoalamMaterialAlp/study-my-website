Aim: Write a program to implement Depth First Search and Breadth First Search.

🖥️ Requirements

Personal Computer or Laptop, C compiler (Turbo C/C++ or Visual Studio Code with C extension).

📌 Purpose

To understand and implement the practical concept of depth first search and breadth first search using C language.

Introduction / Theory

DFS explores a graph deeply before backtracking, while BFS explores vertices level by level using a queue.

Procedure

01

Step 1

1. Represent the graph using an adjacency matrix.

02

Step 2

2. Select a starting vertex.

03

Step 3

3. For DFS, recursively visit unvisited adjacent vertices.

04

Step 4

4. For BFS, use a queue to visit adjacent vertices level by level.

05

Step 5

5. Display the traversal order.

C Program

c 
#include <stdio.h>
#define MAX 20

int graph[MAX][MAX], visited[MAX], n;

void dfs(int v) {
    int i;
    visited[v] = 1;
    printf("%d ", v);
    for (i = 0; i < n; i++)
        if (graph[v][i] && !visited[i])
            dfs(i);
}

void bfs(int start) {
    int queue[MAX], front = 0, rear = 0, i, v;
    for (i = 0; i < n; i++) visited[i] = 0;

    queue[rear++] = start;
    visited[start] = 1;

    while (front < rear) {
        v = queue[front++];
        printf("%d ", v);
        for (i = 0; i < n; i++) {
            if (graph[v][i] && !visited[i]) {
                visited[i] = 1;
                queue[rear++] = i;
            }
        }
    }
}

int main() {
    int i, j, start;
    printf("Enter number of vertices: ");
    scanf("%d", &n);

    printf("Enter adjacency matrix:\n");
    for (i = 0; i < n; i++)
        for (j = 0; j < n; j++)
            scanf("%d", &graph[i][j]);

    printf("Enter starting vertex: ");
    scanf("%d", &start);

    for (i = 0; i < n; i++) visited[i] = 0;
    printf("DFS: ");
    dfs(start);

    printf("\nBFS: ");
    bfs(start);

    return 0;
}
