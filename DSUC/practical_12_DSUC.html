Aim: Write a program to implement Binary Search Tree.

🖥️ Requirements

Personal Computer or Laptop, C compiler (Turbo C/C++ or Visual Studio Code with C extension).

📌 Purpose

To understand and implement the practical concept of binary search tree using C language.

Introduction / Theory

A Binary Search Tree (BST) is a binary tree in which values smaller than a node are placed in its left subtree and larger values are placed in its right subtree.

Procedure

01

Step 1

1. Create a root node.

02

Step 2

2. Insert each value according to BST rules.

03

Step 3

3. Compare the new value with the current node.

04

Step 4

4. Move left for smaller values and right for larger values.

05

Step 5

5. Perform inorder traversal to display sorted values.

C Program

c 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *left, *right;
};

struct Node* createNode(int value) {
    struct Node* node = (struct Node*)malloc(sizeof(struct Node));
    node->data = value;
    node->left = node->right = NULL;
    return node;
}

struct Node* insert(struct Node* root, int value) {
    if (root == NULL) return createNode(value);

    if (value < root->data)
        root->left = insert(root->left, value);
    else if (value > root->data)
        root->right = insert(root->right, value);

    return root;
}

void inorder(struct Node* root) {
    if (root != NULL) {
        inorder(root->left);
        printf("%d ", root->data);
        inorder(root->right);
    }
}

int main() {
    struct Node* root = NULL;
    int n, value, i;

    printf("Enter number of nodes: ");
    scanf("%d", &n);

    for (i = 0; i < n; i++) {
        scanf("%d", &value);
        root = insert(root, value);
    }

    printf("Inorder traversal: ");
    inorder(root);

    return 0;
}
