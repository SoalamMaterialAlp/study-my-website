Q1

What are the various operations on Stack?

Answer: Stack

  • Stack is a type of linear data structure.
  • It follows the LIFO (Last In, First Out) principle.
  • A stack can be implemented using an array or a linked list.
  • In an array implementation, elements are stored in contiguous memory locations.
  • In a linked-list implementation, nodes may be stored in non-contiguous memory locations.
  • All insertion and deletion operations take place at one end called the TOP.
Operations on Stack
  1. Push()
  2. Pop()
  3. Peek()
  4. IsFull()
  5. IsEmpty()
1. Push()
  • Push is a basic stack operation.
  • It inserts a new element into the stack.
  • The element is always added at the top.
  • Before pushing, the stack is checked for overflow in a fixed-size array implementation.
  • If the stack is full, the push operation cannot be performed.
  • When an element is pushed, TOP is incremented and the new element is stored at the top position.
2. Pop()
  • Pop is a basic stack operation used to remove an element.
  • The element is always removed from the top of the stack.
  • Before popping, the stack is checked for underflow.
  • If the stack is empty, the pop operation cannot be performed.
  • The top element is removed and TOP is decremented.
3. Peek()
  • Peek is used to view the top element of the stack.
  • The element is displayed without removing it.
  • The value of TOP remains unchanged.
  • If the stack is empty, the peek operation cannot return a valid top element.
  • Peek helps identify which element will be popped next.
4. IsFull()
  • IsFull checks whether the stack is full.
  • It is mainly used in array-based stack implementations.
  • If TOP == MAX - 1, the stack is full.
  • It helps prevent insertion beyond the array's capacity.
  • It returns true if the stack is full; otherwise, it returns false.
5. IsEmpty()
  • IsEmpty checks whether the stack contains any elements.
  • If TOP == -1 in an array-based stack, the stack is empty.
  • In a linked-list implementation, the stack is empty when TOP == NULL.
  • It helps prevent invalid pop and peek operations.
Q2

What is the basic difference between Stack and Queue?

Answer: The basic differences between Stack and Queue are given below.

Basis Stack Queue
Definition A linear data structure that follows LIFO. A linear data structure that follows FIFO.
Principle Last In, First Out. First In, First Out.
Insertion Insertion is performed using Push at the TOP. Insertion is performed using Enqueue at the REAR.
Deletion Deletion is performed using Pop from the TOP. Deletion is performed using Dequeue from the FRONT.
Access Points Insertion and deletion occur at the same end. Insertion and deletion occur at different ends.
Pointers Usually uses a TOP pointer or index. Usually uses FRONT and REAR pointers or indices.
Removal Order The last inserted element is removed first. The first inserted element is removed first.
Real-Life Example A stack of plates. A line of people waiting for tickets.
Applications Function calls, recursion and expression evaluation. Scheduling, buffering and task management.
Complexity Push and Pop generally take O(1) time. Enqueue and Dequeue generally take O(1) time in a suitable implementation.
Q3

What are the advantages and disadvantages of Stack?

Answer: Stack

  • Stack is a linear data structure.
  • It follows the LIFO (Last In, First Out) principle.
  • Insertion is called Push().
  • Deletion is called Pop().
  • Peek() is used to view the top element.
  • Insertion and deletion both take place at the TOP.
  • Overflow may occur when a fixed-size stack is full.
  • Underflow occurs when an element is removed from an empty stack.
Operations of Stack
  • Push()
  • Pop()
  • Peek()
  • IsFull()
  • IsEmpty()
Advantages of Stack
  • Simple Structure: A stack is easy to understand and implement.
  • Easy Implementation: It can be implemented using an array or linked list.
  • LIFO Principle: It follows the Last In, First Out method.
  • Fast Operations: Push and Pop generally take O(1) time.
  • Dynamic Memory: A linked-list stack can grow dynamically as memory permits.
  • Function Call Management: Stacks help manage function calls.
  • Recursion: Function calls are commonly managed using a call stack.
  • Expression Evaluation: Stacks are used to evaluate prefix and postfix expressions.
  • Expression Conversion: They help convert infix expressions to postfix or prefix.
  • Parenthesis Checking: Stacks help check balanced parentheses.
  • Backtracking: They are useful in maze solving and Depth First Search.
  • Undo and Redo: They help maintain previous actions in applications.
  • Syntax Parsing: Stacks are used in parsing and compiler design.
  • Reversing Data: They can reverse strings and sequences.
  • Browser History: Stack-like structures can help implement navigation history.
Disadvantages of Stack
  • Fixed Size: An array-based stack has a limited capacity unless resized.
  • Stack Overflow: An insertion may fail when a fixed-size stack is full.
  • Stack Underflow: Removing an element from an empty stack is invalid.
  • No Direct Random Access: Middle elements cannot be accessed directly through standard stack operations.
  • Limited Order: Elements follow the LIFO principle.
  • Memory Wastage: Unused array capacity may waste memory.
  • Not Suitable for FIFO Tasks: A standard stack does not provide queue behaviour.
  • Deep Recursion: Excessive function calls may exhaust available call-stack memory.
  • Sequential Access: Standard stack operations focus on the top element.

Q5

Write down the implementation of Stack using a Linked List.

Answer: A stack is a linear data structure that follows the LIFO (Last In, First Out) principle. This means the element inserted last is removed first.

Basic Operations of Stack
  • Push(): Inserts an element into the stack.
  • Pop(): Removes the top element from the stack.
  • Peek(): Displays the top element without removing it.
  • IsEmpty(): Checks whether the stack is empty.
Implementation Using a Linked List
  • Each node contains data and a pointer to the next node.
  • The TOP pointer points to the first node of the linked list.
  • Insertion and deletion are performed at the beginning of the list.
  • The stack can grow dynamically as memory permits.
Structure of a Node
struct Node {
    int data;
    struct Node *next;
};
Complete C Program
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

struct Node *top = NULL;

/* Push an element */
void push(int value) {
    struct Node *newNode =
        (struct Node *)malloc(sizeof(struct Node));

    if (newNode == NULL) {
        printf("Memory allocation failed\n");
        return;
    }

    newNode->data = value;
    newNode->next = top;
    top = newNode;

    printf("%d pushed into stack\n", value);
}

/* Pop an element */
void pop(void) {
    if (top == NULL) {
        printf("Stack Underflow\n");
        return;
    }

    struct Node *temp = top;

    printf("Popped element: %d\n", top->data);

    top = top->next;
    free(temp);
}

/* Peek at the top element */
void peek(void) {
    if (top == NULL) {
        printf("Stack is Empty\n");
    } else {
        printf("Top element: %d\n", top->data);
    }
}

/* Check whether stack is empty */
int isEmpty(void) {
    return top == NULL;
}

/* Display the stack */
void display(void) {
    struct Node *temp = top;

    if (temp == NULL) {
        printf("Stack is Empty\n");
        return;
    }

    printf("Stack elements: ");

    while (temp != NULL) {
        printf("%d ", temp->data);
        temp = temp->next;
    }

    printf("\n");
}

/* Free remaining nodes */
void clearStack(void) {
    while (top != NULL) {
        struct Node *temp = top;
        top = top->next;
        free(temp);
    }
}

int main(void) {
    push(10);
    push(20);
    push(30);

    display();
    peek();

    pop();
    display();

    if (isEmpty()) {
        printf("Stack is Empty\n");
    } else {
        printf("Stack is not Empty\n");
    }

    clearStack();

    return 0;
}
1. Push()

Push inserts a new element at the top of the stack.

  • Step 1: Create a new node.
  • Step 2: Assign data to the new node.
  • Step 3: Set the new node's next pointer to TOP.
  • Step 4: Update TOP to point to the new node.
2. Pop()

Pop removes the top element from the stack.

  • Step 1: Check whether the stack is empty.
  • Step 2: Store the top node in a temporary pointer.
  • Step 3: Move TOP to the next node.
  • Step 4: Free the removed node's memory.
3. Peek()

Peek displays the top element without removing it.

void peek(void) {
    if (top == NULL) {
        printf("Stack is Empty\n");
    } else {
        printf("Top element: %d\n", top->data);
    }
}
4. IsEmpty()

IsEmpty returns 1 if the stack is empty; otherwise, it returns 0.

int isEmpty(void) {
    if (top == NULL) {
        return 1;
    } else {
        return 0;
    }
}
