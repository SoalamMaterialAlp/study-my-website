Aim: Write a program to implement double linked list.

🖥️ Requirements

Personal Computer or Laptop, C compiler (Turbo C/C++ or Visual Studio Code with C extension).

📌 Purpose

To understand and implement the practical concept of doubly linked list using C language.

Introduction / Theory

A doubly linked list contains nodes with data, a pointer to the previous node and a pointer to the next node.

Procedure

01

Step 1

1. Create nodes dynamically.

02

Step 2

2. Set previous and next links.

03

Step 3

3. Traverse forward through next links.

04

Step 4

4. Traverse backward through previous links.

05

Step 5

5. Display the list.

C Program

c 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *prev, *next;
};

int main() {
    struct Node *head = NULL, *tail = NULL, *newNode, *temp;
    int n, i;

    printf("Enter number of nodes: ");
    scanf("%d", &n);

    for (i = 0; i < n; i++) {
        newNode = (struct Node*)malloc(sizeof(struct Node));
        scanf("%d", &newNode->data);
        newNode->prev = newNode->next = NULL;

        if (head == NULL) head = tail = newNode;
        else {
            tail->next = newNode;
            newNode->prev = tail;
            tail = newNode;
        }
    }

    printf("Forward: ");
    for (temp = head; temp != NULL; temp = temp->next)
        printf("%d ", temp->data);

    printf("\nBackward: ");
    for (temp = tail; temp != NULL; temp = temp->prev)
        printf("%d ", temp->data);

    return 0;
}
