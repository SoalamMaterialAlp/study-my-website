Practical No.-1

Aim: Write a program using recursive and non-recursive functions to perform search operation in a given list of integers using linear search technique.

🖥️ Requirements

Personal Computer or Laptop, C compiler (Turbo C/C++ or Visual Studio Code with C extension).

📌 Purpose

To understand and implement the practical concept of linear search using recursive and non-recursive functions using C language.

Introduction / Theory

Linear search checks each element of a list one by one until the required element is found or the list ends.

Procedure

01

Step 1

1. Read the number of elements and array values.

02

Step 2

2. Read the search element.

03

Step 3

3. Perform linear search using an iterative function.

04

Step 4

4. Perform linear search using a recursive function.

05

Step 5

5. Display whether the element is found and its position.

C Program

c 
#include <stdio.h>

int linearRecursive(int a[], int n, int key, int i) {
    if (i >= n) return -1;
    if (a[i] == key) return i;
    return linearRecursive(a, n, key, i + 1);
}

int linearNonRecursive(int a[], int n, int key) {
    int i;
    for (i = 0; i < n; i++)
        if (a[i] == key) return i;
    return -1;
}

int main() {
    int a[100], n, key, i, r1, r2;

    printf("Enter number of elements: ");
    scanf("%d", &n);

    printf("Enter elements: ");
    for (i = 0; i < n; i++) scanf("%d", &a[i]);

    printf("Enter element to search: ");
    scanf("%d", &key);

    r1 = linearNonRecursive(a, n, key);
    r2 = linearRecursive(a, n, key, 0);

    printf("Non-recursive result: %s
", r1 == -1 ? "Not Found" : "Found");
    printf("Recursive result: %s
", r2 == -1 ? "Not Found" : "Found");

    return 0;
}
