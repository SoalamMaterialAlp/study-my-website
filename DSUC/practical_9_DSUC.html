Aim: Write a program to implement Linear and Binary Search.

🖥️ Requirements

Personal Computer or Laptop, C compiler (Turbo C/C++ or Visual Studio Code with C extension).

📌 Purpose

To understand and implement the practical concept of linear and binary search using C language.

Introduction / Theory

Linear search examines elements sequentially. Binary search repeatedly divides a sorted array into two halves to locate the required element.

Procedure

01

Step 1

1. Read the array.

02

Step 2

2. Perform linear search.

03

Step 3

3. Sort the array before binary search if necessary.

04

Step 4

4. Set low, high and mid values.

05

Step 5

5. Compare the key with the middle element and continue in the appropriate half.

C Program

c 
#include <stdio.h>

int linearSearch(int a[], int n, int key) {
    int i;
    for (i = 0; i < n; i++)
        if (a[i] == key) return i;
    return -1;
}

int binarySearch(int a[], int n, int key) {
    int low = 0, high = n - 1, mid;
    while (low <= high) {
        mid = (low + high) / 2;
        if (a[mid] == key) return mid;
        if (key < a[mid]) high = mid - 1;
        else low = mid + 1;
    }
    return -1;
}

int main() {
    int a[100], n, key, i, temp;
    printf("Enter sorted array size: ");
    scanf("%d", &n);
    printf("Enter elements in sorted order: ");
    for (i = 0; i < n; i++) scanf("%d", &a[i]);

    printf("Enter key: ");
    scanf("%d", &key);

    printf("Linear Search index: %d\n", linearSearch(a, n, key));
    printf("Binary Search index: %d\n", binarySearch(a, n, key));
    return 0;
}
