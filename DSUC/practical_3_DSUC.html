Aim: Write a program to implement different operations in Array.

🖥️ Requirements

Personal Computer or Laptop, C compiler (Turbo C/C++ or Visual Studio Code with C extension).

📌 Purpose

To understand and implement the practical concept of different operations in array using C language.

Introduction / Theory

Common array operations include traversal, insertion, deletion and searching.

Procedure

01

Step 1

1. Read the array.

02

Step 2

2. Display the array.

03

Step 3

3. Insert an element at a selected position.

04

Step 4

4. Delete an element from a selected position.

05

Step 5

5. Search for an element.

06

Step 6

6. Display the updated array.

C Program

c 
#include <stdio.h>

int main() {
    int a[100], n, i, pos, value, key, found = 0;

    printf("Enter number of elements: ");
    scanf("%d", &n);

    printf("Enter elements: ");
    for (i = 0; i < n; i++) scanf("%d", &a[i]);

    printf("Enter position for insertion (1-%d): ", n + 1);
    scanf("%d", &pos);
    printf("Enter value: ");
    scanf("%d", &value);

    for (i = n; i >= pos; i--) a[i] = a[i - 1];
    a[pos - 1] = value;
    n++;

    printf("After insertion: ");
    for (i = 0; i < n; i++) printf("%d ", a[i]);

    printf("\nEnter position for deletion (1-%d): ", n);
    scanf("%d", &pos);
    for (i = pos - 1; i < n - 1; i++) a[i] = a[i + 1];
    n--;

    printf("After deletion: ");
    for (i = 0; i < n; i++) printf("%d ", a[i]);

    printf("\nEnter element to search: ");
    scanf("%d", &key);
    for (i = 0; i < n; i++)
        if (a[i] == key) { found = 1; break; }

    printf(found ? "\nElement found." : "\nElement not found.");
    return 0;
}
