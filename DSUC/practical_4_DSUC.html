Practical No.-4

Aim: Write a program to implement different Stack operations.

🖥️ Requirements

Personal Computer or Laptop, C compiler (Turbo C/C++ or Visual Studio Code with C extension).

📌 Purpose

To understand and implement the practical concept of stack operations using C language.

Introduction / Theory

A stack is a linear data structure that follows the LIFO (Last In, First Out) principle. Basic operations are push, pop, peek and display.

Procedure

01

Step 1

1. Initialize top as -1.

02

Step 2

2. Perform push to insert an element.

03

Step 3

3. Perform pop to remove the top element.

04

Step 4

4. Perform peek to view the top element.

05

Step 5

5. Display stack elements.

C Program

c 
#include <stdio.h>
#define MAX 100

int stack[MAX], top = -1;

void push(int x) {
    if (top == MAX - 1) printf("Stack Overflow\n");
    else stack[++top] = x;
}

void pop() {
    if (top == -1) printf("Stack Underflow\n");
    else printf("Popped: %d\n", stack[top--]);
}

void peek() {
    if (top == -1) printf("Stack is empty\n");
    else printf("Top: %d\n", stack[top]);
}

void display() {
    int i;
    if (top == -1) printf("Stack is empty\n");
    else {
        for (i = top; i >= 0; i--) printf("%d ", stack[i]);
        printf("\n");
    }
}

int main() {
    int choice, value;
    do {
        printf("\n1.Push 2.Pop 3.Peek 4.Display 5.Exit\n");
        scanf("%d", &choice);
        switch (choice) {
            case 1: scanf("%d", &value); push(value); break;
            case 2: pop(); break;
            case 3: peek(); break;
            case 4: display(); break;
        }
    } while (choice != 5);
    return 0;
}
