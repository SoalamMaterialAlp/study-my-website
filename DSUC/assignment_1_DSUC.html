Q1

Explain data type in C?

A data type specifies the type of information a variable can store and determines the operations that can be performed on it.

Types of Data Types
  1. Primitive Data Types: int, float, double, char and void.
  2. Derived Data Types: Arrays, pointers and function types.
  3. User-Defined Data Types: Structures, unions, enumerations and type aliases created using typedef.
1. Primitive Data Types
  • Primitive data types are the basic types provided by the C language.
  • They are used to represent integers, floating-point numbers and characters.
(i) int
  • int is used to store integer values without decimal parts.
  • It can represent positive and negative numbers, as well as zero.
  • The %d format specifier is commonly used to print an int value.
  • The size of int depends on the implementation. It is commonly 4 bytes.
  • A typical 32-bit int has a range from -2147483648 to 2147483647. 
int a = 35;
printf("A: %d\n", a);
(ii) float
  • float is used to store floating-point numbers.
  • It can represent fractional values.
  • It commonly occupies 4 bytes of memory.
  • The %f format specifier is commonly used to print a float value. 
float price = 99.99f;
printf("Price: %f\n", price);
(iii) double
  • double is used to store floating-point numbers with greater precision than float on typical systems.
  • It commonly occupies 8 bytes of memory.
  • It is useful when higher precision is required. 
double pi = 3.141592;
printf("Pi: %f\n", pi);
(iv) char
  • char is used to store a character value.
  • Character constants are written using single quotation marks.
  • A char object occupies exactly one byte.
  • The %c format specifier is used to print a character. 
char a = 'K';
printf("Character: %c\n", a);
(v) void
  • void represents the absence of a value.
  • It is commonly used as the return type of a function that returns no value.
  • void can also indicate that a function takes no parameters. 
void display(void)
{
    printf("Hello World");
}
2. Derived Data Types

Derived types are constructed from other types and help organize and manipulate data.

(i) Array
  • An array stores multiple elements of the same type.
  • Its elements occupy contiguous memory locations.
  • Array indexing starts from zero.
Array Declaration: 
data_type array_name[size];

int a[5];
Array Initialization: 
int a[5] = {1, 2, 3, 4, 5};
Accessing Array Elements: 
int a[5] = {1, 2, 3, 4, 5};

printf("%d", a[0]);
Output: 1
Types of Arrays
  1. One-Dimensional Array: Stores elements in a single sequence.
  2. Two-Dimensional Array: Stores elements in rows and columns.
  3. Multidimensional Array: An array with more than two dimensions.
One-Dimensional Array: 
int a[5] = {1, 2, 3, 4, 5};
Two-Dimensional Array: 
int a[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

Here, 2 represents the number of rows and 3 represents the number of columns.

Multidimensional Array: 
int a[2][3][4];
(ii) Pointer
  • A pointer stores the address of an object or function, depending on its type.
  • The * symbol is used in pointer declarations.
  • The & operator obtains the address of an object. 
int a = 20;
int *b = &a;

printf("%d", *b);
Output: 20
(iii) Function
  • A function is a named block of code that performs a particular task.
  • Functions divide programs into smaller and manageable parts.
  • They reduce code repetition and improve readability.
  • Functions can accept parameters and return values.
Function Declaration: 
int add(int a, int b);
Function Definition: 
int add(int a, int b)
{
    return a + b;
}
Complete Function Program: 
#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main(void)
{
    int result;

    result = add(10, 20);

    printf("Sum: %d\n", result);

    return 0;
}
Output: Sum: 30
3. User-Defined Data Types

User-defined types and type aliases help programmers organize and represent data according to program requirements.

(i) Structure (struct)
  • A structure groups variables of different data types under one name.
  • Each member has its own storage within the structure. 
struct person
{
    char name[20];
    int age;
};
(ii) Union (union)
  • A union allows different members to share the same memory.
  • Its size is sufficient to accommodate its largest member, including alignment.
  • Only one member's value can be stored meaningfully at a time. 
union Data
{
    int i;
    float f;
};
(iii) Enumeration (enum)
  • An enumeration defines named integer constants.
  • It makes code easier to read. 
enum Day
{
    Monday,
    Tuesday,
    Wednesday
};
(iv) typedef
  • typedef provides an alternative name for an existing type.
  • It can make declarations easier to read. 
typedef unsigned int unit;

unit age = 25;
Q2

Explain the different types of pointers in C?

A pointer is a variable that stores the address of another object or function, depending on its type.

Pointer Syntax: 
data_type *pointer_name;
Different Types of Pointers
(i) Null Pointer
  • A null pointer does not point to a valid object or function.
  • It can be initialized using NULL. 
int *ptr = NULL;
(ii) Void Pointer
  • A void pointer can hold the address of an object of any data type.
  • It must be converted to an appropriate object pointer type before dereferencing. 
int a = 5;

void *ptr = &a;

printf("%d", *(int *)ptr);
(iii) Dangling Pointer
  • A dangling pointer refers to an object whose lifetime has ended or whose allocated memory has been freed.
  • Using it can cause undefined behavior. 
#include <stdlib.h>

int *ptr = malloc(sizeof(int));

if (ptr != NULL)
{
    *ptr = 10;

    free(ptr);
    ptr = NULL;
}
(iv) Wild Pointer
  • A wild pointer is an uninitialized pointer.
  • Its value is indeterminate.
  • It must not be dereferenced before being initialized. 
int *ptr;

/* Initialize ptr before using it. */
(v) Function Pointer
  • A function pointer stores the address of a function.
  • It can be used to call that function indirectly. 
int add(int a, int b)
{
    return a + b;
}

int (*func_ptr)(int, int) = add;

printf("%d", func_ptr(10, 20));
Output: 30
(vi) Pointer to Pointer
  • A pointer to pointer stores the address of another pointer. 
int a = 10;

int *ptr = &a;

int **ptr2 = &ptr;

printf("%d", **ptr2);
Output: 10
(vii) Constant Pointer
  • The pointer's address cannot be changed after initialization.
  • The pointed-to value can be changed if the object is not constant. 
int a = 5;
int b = 10;

int * const ptr = &a;

*ptr = 7;

/* ptr = &b;  Not allowed */
(viii) Pointer to Constant
  • The pointed-to value cannot be changed through this pointer.
  • The pointer can be changed to point to another compatible object. 
int a = 10;
int b = 20;

const int *ptr = &a;

ptr = &b;

/* *ptr = 30;  Not allowed */
Q3

What is the basic difference between time complexity and space complexity?

Time complexity and space complexity are used to analyze the efficiency of algorithms.

Time complexity describes how computational work grows with input size, while space complexity describes how memory requirements grow with input size.

Feature Time Complexity Space Complexity
Definition Describes how the computational work of an algorithm grows with input size. Describes how the memory requirements of an algorithm grow with input size.
Purpose Analyzes algorithm efficiency in terms of computational work. Analyzes algorithm efficiency in terms of memory usage.
Depends On Operations, loops and recursive calls. Variables, arrays, recursion, stacks and data structures.
Notation O(1), O(n), O(n²), etc. O(1), O(n), O(n²), etc.
Effect Relates to execution-time growth. Relates to memory requirements.
Trade-off Reducing computational work may require additional memory. Reducing memory usage may require additional computational work.
Design Tip Avoid unnecessary operations and repeated work. Use memory and data structures efficiently.
Q4

Explain the various types of notations used in complexity analysis.

Asymptotic notations describe how an algorithm's time or space requirements grow as the input size increases.

(i) Big O Notation — O
  • Big O represents an asymptotic upper bound on a function's growth.
  • It is commonly used to describe worst-case time complexity.
  • It describes how computational work grows as input size increases.
  • Example: Linear search has O(n) worst-case time complexity.
Mathematical Definition:

f(n) = O(g(n)) if there exist positive constants c and n₀ such that:

0 ≤ f(n) ≤ c · g(n), for all n ≥ n₀.

(ii) Big Omega Notation — Ω
  • Big Omega represents an asymptotic lower bound on a function's growth.
  • It can describe best-case time complexity when the input case is specified.
  • Example: Linear search has Ω(1) best-case time complexity.
Mathematical Definition:

f(n) = Ω(g(n)) if there exist positive constants c and n₀ such that:

0 ≤ c · g(n) ≤ f(n), for all n ≥ n₀.

(iii) Theta Notation — Θ
  • Theta represents a tight asymptotic bound on a function's growth.
  • It means the function has matching upper and lower bounds within constant factors.
  • Example: A loop that executes n times and performs constant work per iteration has Θ(n) time complexity.
Mathematical Definition:

f(n) = Θ(g(n)) if there exist positive constants c₁, c₂ and n₀ such that:

0 ≤ c₁ · g(n) ≤ f(n) ≤ c₂ · g(n), for all n ≥ n₀.
