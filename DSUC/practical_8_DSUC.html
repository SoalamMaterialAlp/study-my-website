Aim: Write a program to implement circular linked list.

🖥️ Requirements

Personal Computer or Laptop, C compiler (Turbo C/C++ or Visual Studio Code with C extension).

📌 Purpose

To understand and implement the practical concept of circular linked list using C language.

Introduction / Theory

In a circular linked list, the last node points back to the first node instead of containing NULL.

Procedure

01

Step 1

1. Create nodes dynamically.

02

Step 2

2. Link each node with the next node.

03

Step 3

3. Link the last node to the head.

04

Step 4

4. Traverse until the head is reached again.

05

Step 5

5. Display the circular list.

C Program

c 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

int main() {
    struct Node *head = NULL, *tail = NULL, *newNode, *temp;
    int n, i;

    printf("Enter number of nodes: ");
    scanf("%d", &n);

    for (i = 0; i < n; i++) {
        newNode = (struct Node*)malloc(sizeof(struct Node));
        scanf("%d", &newNode->data);

        if (head == NULL) {
            head = tail = newNode;
            newNode->next = head;
        } else {
            newNode->next = head;
            tail->next = newNode;
            tail = newNode;
        }
    }

    printf("Circular List: ");
    if (head != NULL) {
        temp = head;
        do {
            printf("%d ", temp->data);
            temp = temp->next;
        } while (temp != head);
    }

    return 0;
}
