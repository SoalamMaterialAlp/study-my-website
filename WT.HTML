Detailed Course Content

Syllabus

UNIT 1: Web Development Introduction

WWW, Internet, Browser, Search engine Client Server Model, URL, Web Pages, Website and Web Services, Types of Websites (Static, Dynamic and Responsive), Developer options of Browser (View page source, Developer Tools, Inspect Element etc)

UNIT 2 : HTML Basics

HTML Document, Basic Structure of HTML, Syntax, HTML Tags and Attributes, Types of HTML Tags, Rules of nesting, Basic Tags (HTML Tag. Head Tag, Title Tag, Body Tags). Page Formatting: Adding a new Paragraph, Adding a line break, Inserting a blank space, changing page background, Div and Span tags Text Formatting: Html Headings, Formatting elements (<b> Bold text, <strong> Important text,<i> Italic text, <em> Emphasized text, <mark> Marked text, <small> Small text, <del> Deleted text, <ins> Inserted text, <sub> Subscript text, <sup> Superscript text), Comments, Horizontal Lines Creating Lists: Ordered List, Unordered Lists, Definition Lists Others: Images, Text Links, Image Links, opening a page in New Window or Tab, Linking to an area of same page, Introduction to Table Tags, Frames & I frame, HTML Forms

UNIT 3: Cascading Style Sheets :

Introduction, Benefits of CSS, CSS Syntax, CSS Implementation (inline, internal and external), CSS Selectors (ID Selectors, Class Selectors, Grouping Selectors, Universal Selectors, CSS Pseudo-classes), CSS properties (background-color, background-image, border-style, height, width, color, text-align, font-family, font-style, font-size, font- weight), Box Model in CSS (margin, border, padding)

UNIT 4: JavaScripts :

Java Script Introduction , variables , data types , operators, control flow (if-else, for loop, while loop, do-while loop), Declaring Functions, Calling functions with parameters, Adding JavaScript to Web Documents, JavaScript Objects, Document Object Models, HTML Events and calling Java Script functions on Events

UNIT 5: PHP :

Server side scripting, Arrays, function and forms, advance PHP Databases: Basic command with PHP examples, Connection to server, creating database, selecting a database, listing database, listing table names creating a table, inserting data, altering tables, queries, deleting database, deleting data and tables, PHP my admin and database bugs.

Deadlock

Avoidance, prevention and Banker's Algorithm.

Page Replacement

FIFO, LRU and OPTIMAL algorithms.

Memory Allocation

First Fit, Best Fit and Worst Fit.

Disk Scheduling

FCFS, SCAN and C-SCAN algorithms.

File Allocation

Sequential, Indexed and Linked allocation.
