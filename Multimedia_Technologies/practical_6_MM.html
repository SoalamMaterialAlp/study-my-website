Practical No. 6

Aim: To learn and use various features of Adobe Photoshop/GIMP for image editing and graphic designing.

🖥️ Requirements

1. Computer system
2. Adobe Photoshop or GIMP
3. Sample images for editing
4. Keyboard and mouse

📌 Purpose

To understand image editing, cropping, resizing, colour correction, text insertion, layer management and the application of filters and effects.

Introduction

Adobe Photoshop and GIMP are popular graphics editing applications used in multimedia technology. They allow users to create, edit, enhance and manipulate digital images for educational, professional and creative purposes.


These applications provide various tools such as selection, cropping, resizing, text insertion, colour adjustment, layers, filters and special effects. These features are useful for designing posters, banners, logos, presentations, advertisements and other multimedia content.

Procedure

01

Open Photoshop/GIMP

Start Adobe Photoshop or GIMP on the computer. Create a new image using the New option, or open an existing image using the Open command from the File menu.

02

Use Selection Tools

Use selection tools such as the Rectangular Selection, Elliptical Selection or Free Select tool to select a specific part of the image. Selected areas can be edited independently.

03

Crop and Resize the Image

Use the Crop tool to remove unwanted areas from the image. Use the image size or scale options to change its dimensions according to the requirements of the project.

04

Adjust Brightness, Contrast and Colours

Use image adjustment tools to improve brightness, contrast, colour balance and saturation. These adjustments help make the image clearer and visually attractive.

05

Add Text to the Image

Select the Text tool and click on the image to insert text. Change the font style, size, colour and alignment to create titles, labels or captions for the design.

06

Work with Layers

Create separate layers for text, images and other design elements. Layers allow individual elements to be edited, moved, hidden or rearranged without directly affecting other elements.

07

Apply Filters and Effects

Apply suitable filters and effects to improve the appearance of the image. Examples include blur, sharpen and artistic effects. Preview the changes and choose effects that suit the design.

08

Save the Edited Image

Save the project in the software's native format to preserve editable layers. Export or save a copy in JPEG or PNG format for sharing and use in multimedia presentations.

09

Review the Final Output

Check the edited image for errors, unwanted elements and incorrect colours. Make any necessary corrections and ensure that the final image meets the design requirements.

⚠️ Precautions

  • Always keep a backup of the original image before making major changes.
  • Use layers carefully so that individual elements can be edited without affecting the entire image.
  • Select the appropriate file format and image dimensions before exporting the final output.

✅ Result

Successfully learned and used various features of Adobe Photoshop/GIMP, including selection tools, cropping, resizing, colour adjustment, text insertion, layer management and filters for image editing and graphic designing.
