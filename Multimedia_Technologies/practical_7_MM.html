Practical No. 7

Aim: To learn and use various features of Blender for 3D modelling, animation, material application, lighting and rendering.

🖥️ Requirements

1. Computer system
2. Blender software
3. Keyboard and mouse
4. Sufficient memory and storage

📌 Purpose

To understand 3D objects, object transformations, materials, lighting, camera settings, animation and rendering using Blender.

Introduction

Blender is a free and open-source 3D creation application used in multimedia technology. It provides tools for 3D modelling, animation, rendering, visual effects and the creation of digital content.


Blender allows users to create objects, apply materials, set up lighting, position cameras and produce animations. It is widely used for educational projects, games, product visualisation, animated films and multimedia presentations.

Procedure

01

Open Blender

Start Blender on the computer and create a new project. The default scene generally contains a cube, a camera and a light source. Familiarise yourself with the 3D Viewport and interface.

02

Create 3D Objects

Use the Add menu to insert basic 3D objects such as cubes, spheres, cylinders and cones. These objects can be used as building blocks for creating different 3D models.

03

Transform Objects

Use the Move, Rotate and Scale tools to change the position, orientation and size of objects. Arrange the objects in the scene to create the desired model.

04

Apply Materials and Colours

Open the Material Properties and create a material for the selected object. Adjust its base colour and other available properties to improve the appearance of the model.

05

Add Lighting

Add or adjust light sources to illuminate the 3D scene. Change the light position, colour and strength to achieve the desired appearance and visibility.

06

Set Up the Camera

Position the camera so that the required objects are visible in the camera view. Adjust its position and orientation to obtain a suitable composition for rendering.

07

Create Animation

Select an object and move the timeline playhead to a chosen frame. Insert a keyframe for the object's position, rotation or scale. Change the object at another frame and insert another keyframe to create a simple animation.

08

Configure Rendering Settings

Open the Render Properties and select a suitable render engine. Set the output resolution and other required options. Check the lighting, materials and camera before rendering the scene.

09

Render and Save the Project

Render the final scene to generate the output image. Save the Blender project using the Save option. Export the rendered output in an appropriate format for future use.

⚠️ Precautions

  • Save the Blender project regularly to avoid losing your work.
  • Check the camera position, materials and lighting before rendering the final scene.
  • Use suitable output settings and ensure that sufficient storage is available for rendered files.

✅ Result

Successfully learned and used various features of Blender, including 3D object creation, object transformations, material application, lighting, camera setup, animation and rendering.
