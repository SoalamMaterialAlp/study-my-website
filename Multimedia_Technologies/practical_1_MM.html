Multimedia Technology

Practical No. 1

Aim: To install various multimedia software such as Adobe Photoshop, GIMP, Blender, Adobe Animate, and other open-source multimedia applications.

🖥️ Requirements

Computer system, internet connection, web browser, installation files, and sufficient storage space.

📌 Purpose

To learn the installation process and basic use of multimedia software for image editing, graphic design, animation, and 3D modelling.

Introduction

Multimedia software is used to create, edit, and manage digital content such as images, audio, video, graphics, and animations. These applications are widely used in education, entertainment, graphic design, and web development.


Adobe Photoshop is used for image editing, GIMP is an open-source image editor, Blender is used for 3D modelling and animation, and Adobe Animate is used to create 2D animations and interactive content.

Procedure

01

Start the Computer

Switch on the computer and ensure that the operating system is working properly. Connect the computer to the internet if online downloading is required.

02

Open a Web Browser

Open a web browser and visit the official website of the required multimedia software. Verify the system requirements before downloading.

03

Download the Software

Download the installation file for Adobe Photoshop, GIMP, Blender, or Adobe Animate. Use the official website or an authorized source.

04

Run the Installer

Locate the downloaded installation file and open it. Follow the on-screen instructions to begin the installation process.

05

Accept the License Agreement

Read the license agreement and accept it when required. Select the installation options according to the software instructions.

06

Select the Installation Location

Choose the destination folder for the software. Ensure that the selected drive has sufficient free storage space.

07

Install the Software

Click the Install button and wait for the installation process to complete. Restart the computer if the installer requests it.

08

Launch the Application

Open the installed software from the Start menu or desktop shortcut. Check whether the application starts without errors.

09

Test the Software

Create a sample image, drawing, or animation to verify that the software is working properly.

⚠️ Precautions

  • Download software only from official or trusted sources.
  • Check system requirements before installation.
  • Ensure sufficient storage space and do not interrupt installation.

✅ Result

Various multimedia software applications were installed and tested successfully.
