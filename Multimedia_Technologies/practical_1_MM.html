Multimedia Technology

Practical No. 1

Aim: To install various multimedia software such as Adobe Photoshop, GIMP, Blender, Adobe Animate, and other open-source multimedia applications.

🖥️ Requirements

Computer system, internet connection, web browser, installation files, and sufficient storage space.

📌 Purpose

To learn the installation process and basic use of multimedia software for image editing, graphic design, animation, and 3D modelling.

Introduction

Multimedia software is used to create, edit, and manage digital content such as images, audio, video, graphics, and animations. These applications are widely used in education, entertainment, graphic design, and web development.


Some popular multimedia software programs are:

  • Adibe Photoshop :- Used for image editing and graphic designing.

  • GIMP :- Used for image editing and manipulation.

  • Blender :- Used for 3D modeling , animation and rendering.

  • Adobe Flash :- Historically used for creating animation and interactive content.

    • GIMP and Blender are example of open-source multimedia software.

    Procedure

    01

    Start the computer and connect it to the internet.

    02

    Open a web browser.

    03

    Visit the official website of the required software.

    04

    Download the software installation file.

    05

    Open the downloaded file.

    06

    Follow the instructions displayed on the screen.

    07

    Accept the license agreement, if required.

    08

    Select the installation location.

    09

    Click the install button.

    10

    After installation, open the software and check whether its work properly.

    ⚠️ Precautions

    • Download software only from official or trusted sources.
    • Check system requirements before installation.
    • Ensure sufficient storage space and do not interrupt installation.

    ✅ Result

    Various multimedia software programs werestudied and the installation procedure was performed successfully.
