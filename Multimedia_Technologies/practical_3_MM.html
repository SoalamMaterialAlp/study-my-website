Practical No. 3

Aim: To read data from and write data to different types of CD/DVD media using a compatible optical disc drive.

🖥️ Requirements

Computer, compatible CD/DVD drive, readable CD/DVD, blank writable disc, data files, and disc-burning software.

📌 Purpose

To understand optical storage media and learn how to copy, burn, and verify files on compatible discs.

Introduction

CDs and DVDs are optical storage media used to store digital information. A laser in the optical drive reads data from the disc. Writable discs can be used to record files, music, videos, and other information.


CD-ROM and DVD-ROM are read-only formats. CD-R and DVD-R are recordable formats, while CD-RW and DVD-RW can be erased and rewritten when supported by the drive and software.

Procedure

01

Identify the Disc and Drive

Check whether the computer has a built-in or external optical drive. Confirm that the drive supports the type of CD/DVD being used.

02

Insert the Disc

Insert a readable CD/DVD into the drive carefully. Wait for the computer to detect the disc.

03

Read Data from the Disc

Open File Explorer and select the CD/DVD drive. View the available files and folders stored on the disc.

04

Copy Files to the Computer

Select the required files from the disc, choose Copy, open a destination folder on the computer, and choose Paste. Open the copied files to verify them.

05

Insert a Writable Disc

Insert a blank CD-R, CD-RW, DVD-R, DVD+R, DVD-RW, or DVD+RW supported by the optical drive. Ensure that the disc has sufficient capacity.

06

Select the Files to Write

Open File Explorer and select the files or folders that you want to store on the disc. Check the total file size before burning.

07

Burn Data to the Disc

Choose the disc-burning option or use compatible disc-burning software. Enter a disc title if required and start the burning process.

08

Complete the Writing Process

Wait until the writing process is complete. Do not interrupt the process or eject the disc while data is being written.

09

Verify the Written Data

Eject the disc safely, insert it again, and open the recorded files. Check whether the data can be read correctly.

Common CD/DVD Formats

CD-ROM: A read-only compact disc.

CD-R: A recordable compact disc that is generally written once.

CD-RW: A rewritable compact disc.

DVD-ROM: A read-only digital versatile disc.

DVD-R/DVD+R: Recordable DVD formats.

DVD-RW/DVD+RW: Rewritable DVD formats.

⚠️ Precautions

  • Use a disc and drive that are compatible with each other.
  • Do not scratch, bend, or touch the data surface unnecessarily.
  • Never interrupt the burning process while data is being written.

✅ Result

Data was read from and written to compatible CD/DVD media, and the recorded files were verified successfully.
