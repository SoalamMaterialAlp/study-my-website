Multimedia Technology

Practical No. 5

Aim: To study and use various features of Adobe Flash or Adobe Animate, including drawing, layers, timeline, frame-by-frame animation, motion tweening, text, sound, and exporting.

🖥️ Requirements

Computer, Adobe Animate or a compatible animation application, mouse, and optional audio files for sound integration.

📌 Purpose

To understand the basic tools and techniques used to create 2D animations and multimedia presentations.

Introduction

Adobe Flash was multimedia software used to create animations, interactive presentations, games, and web content. It provided tools for drawing, text, sound, timelines, layers, and animation effects.


Flash Professional was renamed Adobe Animate. The original Adobe Flash Player was discontinued in 2020. Adobe Animate and other compatible applications can be used to study many traditional Flash animation concepts.

Procedure

01

Create a New Document

Open Adobe Animate or a compatible animation application. Select New Document, choose the required stage dimensions, set the frame rate, and create the document.

02

Draw Objects

Select the Rectangle, Oval, Pencil, or Brush tool. Draw a shape on the stage and adjust its fill colour, stroke colour, size, and position.

03

Work with Layers

Open the Timeline panel and create separate layers for different objects. Rename the layers, arrange them appropriately, and lock or hide layers when required.

04

Create Frame-by-Frame Animation

Draw an object in the first frame. Insert a keyframe in a later frame, change the object's position or appearance, and repeat the process. Play the timeline to observe the animation.

05

Create Motion Tween Animation

Draw an object and convert it into a symbol if required. Insert a starting keyframe and an ending keyframe, create a motion tween, and move the object to its ending position. Preview the animation.

06

Add Text

Select the Text tool and click on the stage. Type the required text and change the font, size, colour, alignment, and position as needed.

07

Add Sound

Import a compatible audio file into the project library. Select the appropriate frame, add the audio to the timeline, configure the available sound settings, and preview the result.

08

Preview the Animation

Play the timeline and check the movement of objects, text, and sound. Correct any timing or positioning problems before exporting the project.

09

Export the Animation

Save the project file. Open the export or publish options, select a supported output format, configure the settings, and export the animation. Open the exported file to verify the result.

Important Features of Flash

Stage: The area where visual content is placed.

Timeline: Controls the sequence and timing of animation frames.

Layers: Organize objects separately within a project.

Keyframes: Define important points in an animation.

Motion Tween: Creates movement between specified object states.

Text Tool: Adds text to the animation.

Library: Stores reusable assets such as symbols, graphics, and imported media.

Export: Produces an output file in a supported format.

⚠️ Precautions

  • Save the project regularly to avoid losing work.
  • Use compatible audio files and supported export formats.
  • Preview the animation and verify the exported file before submission.

✅ Result

Various features of Flash/Animate, including drawing, layers, frame-by-frame animation, motion tweening, text, sound, and exporting, were studied and tested.
