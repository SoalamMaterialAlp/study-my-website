Aim: To study table and record handling using INSERT, SELECT, DELETE, UPDATE, TRUNCATE, DROP and ALTER statements.

🖥️ Requirements

Personal Computer or Laptop
MySQL/XAMPP
phpMyAdmin

📌 Purpose

To study different SQL statements used for managing tables and records.

Theory

SQL provides different commands for creating, modifying and managing database records and tables.

INSERT Statement

The INSERT statement is used to add new records to a table.

SELECT Statement

The SELECT statement is used to retrieve records from a table.

INSERT with SELECT

SELECT can be used together with INSERT to insert selected data from one table into another table.

DELETE Statement

DELETE is used to remove selected records from a table.

UPDATE Statement

UPDATE is used to modify existing records.

TRUNCATE Statement

TRUNCATE removes all records from a table while keeping the table structure.

DROP Statement

DROP removes the database object, such as a table, completely.

ALTER Statement

ALTER is used to modify the structure of an existing table.

  • Add a column
  • Modify a column
  • Rename a column
  • Remove a column

⚠️ Precautions

  • Use SQL statements carefully while modifying records.
  • Verify records before using DELETE or TRUNCATE.
  • Use ALTER and DROP statements carefully because they affect database structure.
