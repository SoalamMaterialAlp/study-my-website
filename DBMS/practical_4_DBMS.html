📌 Purpose

To understand database creation, table creation, relational data types, constraints and indexes.

Theory

A database is an organized collection of related data. Tables are used to store data in rows and columns.

Creating a Database

A database is created to provide a logical container for related tables and data.

Creating a Table

A table consists of columns and rows. Each column represents a field and each row represents a record.

Relational Data Types

  • INT – stores integer values.
  • VARCHAR – stores variable-length text.
  • CHAR – stores fixed-length text.
  • DATE – stores date values.
  • DECIMAL – stores decimal numbers.
  • FLOAT – stores floating-point numbers.

Constraints

Constraints are rules applied to table data.

  • PRIMARY KEY
  • FOREIGN KEY
  • NOT NULL
  • UNIQUE
  • DEFAULT
  • CHECK

Indexes

An index is used to improve the speed of data retrieval from a table. Indexes are especially useful when searching or sorting large amounts of data.

⚠️ Precautions

  • Use appropriate data types for each column.
  • Apply suitable constraints according to the table requirements.
  • Create indexes where they are required for efficient data retrieval.
