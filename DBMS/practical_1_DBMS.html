Database Management System

Practical No. 1

Aim: To install and configure a database management system using MySQL through XAMPP Server.

🖥️ Requirements

Personal Computer or Laptop
XAMPP Server
MySQL
Web Browser
Text Editor

📌 Purpose

To install, configure and verify the working of a MySQL database system using XAMPP Server.

Theory

A Database Management System (DBMS) is software used to create, store, manage and retrieve data from a database. MySQL is a popular relational database management system that uses SQL (Structured Query Language).

XAMPP provides an easy environment for running Apache and MySQL on a local computer. The MySQL service can be started and managed through the XAMPP Control Panel.

Procedure

01

Install XAMPP Server

Download and install XAMPP Server on the computer.

02

Open XAMPP Control Panel

Open the XAMPP Control Panel after installation.

03

Start Services

Start the Apache and MySQL services.

04

Open Browser

Open a web browser on the computer.

05

Open phpMyAdmin

Open phpMyAdmin through the XAMPP interface.

06

Verify MySQL

Verify that the MySQL server is running properly.

07

Create Database

Create a sample database to verify the installation.

08

Verify Installation

Check that the database system is ready for use.

⚠️ Precautions

  • Install XAMPP from a trusted source.
  • Make sure the MySQL service is running before using phpMyAdmin.
  • Do not stop the MySQL service while performing database operations.

✅ Result

Thus, MySQL database system was successfully installed and configured using XAMPP Server.
