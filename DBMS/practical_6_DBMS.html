Practical No. 6

Aim: To study different methods of retrieving data from a database using SQL.

🖥️ Requirements

Personal Computer or Laptop
MySQL/XAMPP
phpMyAdmin

📌 Purpose

To study different SQL clauses, operators, aggregate functions and joins used for retrieving data.

Theory

The SELECT statement is used to retrieve data from database tables.

SELECT Statement

Used to retrieve data from one or more tables.

WHERE Clause

Used to specify a condition for selecting records.

Logical Operators

Logical operators such as AND, OR and NOT can be used to combine conditions.

IN Operator

Used to check whether a value belongs to a specified set of values.

BETWEEN Operator

Used to retrieve values within a specified range.

LIKE Operator

Used to search for a specified pattern in text data.

ORDER BY Clause

Used to arrange query results in ascending or descending order.

GROUP BY Clause

Used to group records having similar values.

HAVING Clause

Used to apply conditions to grouped records.

Aggregate Functions

  • COUNT()
  • SUM()
  • AVG()
  • MAX()
  • MIN()

JOINS

Joins are used to combine records from two or more related tables.

  • INNER JOIN
  • LEFT JOIN
  • RIGHT JOIN

Procedure

01

SELECT

Use SELECT to retrieve data from database tables.

02

WHERE

Use WHERE to specify conditions for retrieving records.

03

Logical Operators

Use AND, OR and NOT to combine conditions.

04

IN, BETWEEN and LIKE

Use IN, BETWEEN and LIKE for filtering and searching data.

05

ORDER BY

Arrange retrieved data in ascending or descending order.

06

GROUP BY and HAVING

Group records and apply conditions to grouped records.

07

Aggregate Functions

Study COUNT(), SUM(), AVG(), MAX() and MIN().

08

JOINS

Study INNER JOIN, LEFT JOIN and RIGHT JOIN for combining related tables.

⚠️ Precautions

  • Use appropriate conditions while retrieving data.
  • Check the column names before applying clauses.
  • Use correct relationships while combining tables with JOINs.

Thus, different techniques for retrieving and combining data from a database were successfully studied.
