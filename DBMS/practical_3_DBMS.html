📌 Purpose

To understand the important components and properties of an ER Model.

Theory

An ER Model consists of several important components used to represent database structure.

1. Entity

An entity represents a real-world object about which data is stored. Example: Student, Book, Employee.

2. Attribute

An attribute describes a property of an entity. Example: StudentID, Name, Address.

3. Relationship

A relationship represents an association between two or more entities.

4. Primary Key

A primary key uniquely identifies each record of an entity.

5. Composite Attribute

An attribute that can be divided into smaller attributes. Example: Name can be divided into FirstName and LastName.

6. Multivalued Attribute

An attribute that can have more than one value for an entity.

7. Derived Attribute

An attribute whose value can be calculated from another attribute.

8. Cardinality

Cardinality defines how many instances of one entity can be associated with another entity.

  • One-to-One
  • One-to-Many
  • Many-to-Many
