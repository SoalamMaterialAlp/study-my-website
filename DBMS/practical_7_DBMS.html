Database Management System

Practical No. 7

Aim: To design and implement a database for a Library Management System and perform different SQL operations.

🖥️ Requirements

Personal Computer or Laptop
MySQL/XAMPP
phpMyAdmin

📌 Purpose

To study database operations for books, members, authors and publishers in a Library Management System.

Scenario

An institute manages a Library Management System. The system stores information about books, members, authors and publishers.

Main Fields

  • BookID
  • Title
  • Author_Name
  • Year_of_publication
  • Publisher_name
  • Subject
  • MemberID

Other fields may also be added according to requirements.

Tasks

1. Retrieve books by specific author "A"

Retrieve the names of all books written by a specific author "A". The Author_Name field is used to search for the required author.

2. Retrieve books of particular subject "X"

Retrieve the names of books belonging to a particular subject "X". The Subject field is used to filter the required books.

3. Decrease book count for BookID "101"

Decrease the book count by 1 for the book having BookID "101".

4. Add a new member

Add a new member record to the Member table.

Procedure

01

Design Library Database

Design the Library Management System database.

02

Create Required Tables

Create the required tables for the database.

03

Define Fields and Relationships

Define appropriate fields and relationships.

04

Insert Records

Insert books and member records.

05

Retrieve Books

Retrieve books according to author and subject.

06

Update Book Count

Decrease the book count for BookID 101.

07

Add Member

Insert a new member record into the database.

⚠️ Precautions

  • Use appropriate fields for books and members.
  • Verify the BookID before updating the book count.
  • Check the member information before inserting a new record.

✅ Result

Thus, the Library Management System case study was successfully designed and the specified database operations were studied.
