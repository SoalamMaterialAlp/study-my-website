Practical No. 2

Aim: To design an Entity Relationship (ER) Model for a Library Management System.

🖥️ Requirements

Personal Computer or Laptop
ER Diagram software or paper and pencil
DBMS software

📌 Purpose

To represent the structure of a Library Management System using entities, attributes and relationships.

Theory

An Entity Relationship Model represents the structure of a database using entities, attributes and relationships.

Major Entities

  • Book
  • Member
  • Author
  • Publisher
  • Issue/Return

Book

  • BookID
  • Title
  • Subject
  • Year_of_publication

Member

  • MemberID
  • MemberName
  • Address
  • Contact

Author

  • AuthorID
  • AuthorName

Publisher

  • PublisherID
  • PublisherName

Issue

  • IssueID
  • IssueDate
  • ReturnDate

Relationships

  • Author writes Book.
  • Publisher publishes Book.
  • Member borrows Book.
  • Issue entity records the issue and return details.

Procedure

01

Identify Entities

Identify the entities required for the Library Management System.

02

Identify Attributes

Identify attributes for each entity.

03

Select Primary Keys

Select suitable primary keys for the entities.

04

Identify Relationships

Identify relationships between entities.

05

Define Cardinality

Define the cardinality of the relationships.

06

Draw ER Diagram

Draw the complete ER diagram.

07

Verify Model

Verify all relationships and attributes.

⚠️ Precautions

  • Use suitable attributes for each entity.
  • Choose unique primary keys.
  • Verify relationships before finalizing the ER Model.

✅ Result

Thus, an ER Model for the Library Management System was successfully designed.
