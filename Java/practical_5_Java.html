Practical No. 05

Aim: To write a Java program to demonstrate the concept of Class and Objects using the Car class.

🖥️ Requirements

  • Computer or Laptop
  • Java Development Kit (JDK)
  • Java IDE (BlueJ, Eclipse, or NetBeans) or Notepad
  • Java Compiler and JVM

    • Theory

  • A class is a blueprint or template used to create objects. It defines the properties and methods of objects.

  • An object is an instance of a class. Each object has its own properties and can use the methods defined in the class.

    • In this program,

  • Car is a class, and Santro Xing, Alto, and Wagon R are represented by three objects: c1, c2, and c3.

  • The properties of the Car class are model, year, colour, and topSpeed. The methods are Create(), Sold(), and display().
