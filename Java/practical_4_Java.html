Practical No. 04

Aim : To write a java program to perform string operations such as comparing two strings, reversing a string and changing the case of a string using built-in string methods.

🖥️ Requirements

  • Computer or Laptop
  • Java Development Kit (JDK)
  • Java IDE (BlueJ, Eclipse, or NetBeans) or Notepad
  • Java Compiler and JVM

    • Theory

  • In Java a String is a sequence of character Java provides several built-in methods to perform operations on string.

    • The following methods are used in this program:-

  • equals():- Compares two strings and checks whether their contents are equal.

  • reverse():- Reverse a string. This method is provided by the String Builder class.

  • toUpperCase():- Converts all lower case letters into Upper case letters.

  • toLowerCase():-Converts all upper case letters into lower case letters.

  • Scanner():- Takes string / value input from the user.
