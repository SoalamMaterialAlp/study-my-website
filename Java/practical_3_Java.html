Aim: To write a java program to demonstrate the use of abstract classes and abstract methods.

🖥️ Requirements

  • Computer or Laptop
  • Java Development Kit (JDK)
  • Java IDE (BlueJ, Eclipse, or NetBeans) or Notepad
  • Java Compiler and JVM

    • Theory

  • An abstract class is a class declared with the abstract keyword. We cannot create an object of an abstract class directly.

  • An abstract method is a method that is declared without a body.The subclass provides the implementation of the abstract methods.

    • In this program,

  • Shape is an abstract class.

  • area() is an abstract method.

  • Circle and Rectangle inherit the shap class.

  • Both classes implement the area() method to calculate their respective areas.
