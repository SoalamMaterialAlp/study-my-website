OOPS Using Java

Practical No. 06

Aim: To create an Employee base class that provides common properties and behaviours to different types of employees in a software company, where their roles, responsibilities and perks differ.

🖥️ Requirements

  • Computer or Laptop
  • Java Development Kit (JDK)
  • Java IDE (BlueJ, Eclipse, or NetBeans) or Notepad
  • Java Compiler and JVM

    • Theory

  • Inheritance is an important feature of Object-Oriented Programming (OOP) in Java. It allows one class to acquire the properties and methods of another class.

    In this program,

  • Employee is the base class that contains common properties such as Employee ID, Name, Designation and Salary, along with methods to display employee details and work information.

  • Different employee classes, such as SoftwareEngineer, SrSoftwareEngineer, ProjectManager, ProjectLead, ProgramManager, TechnicalLead, ModuleLead and Director, inherit the Employee class using the extends keyword.

  • Inheritance promotes code reusability and reduces code duplication.
