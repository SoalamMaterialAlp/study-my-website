Q1

What is Inheritance and its advantages ?

Answer: Inheritance is the process by which one class acquires the properties and behaviors (fields and methods) of another class.

The class whose properties are inherited is called the Parent/Superclass, and the class that inherits those properties is called the Child/Subclass.

Inheritance helps in code reusability, reduces code duplication, and makes programs easier to maintain.

In Java, inheritance is implemented using the extends keyword.

Advantages of Inheritance :-

Inheritance provides several advantages:

(i)Code Reusability : Existing code can be reused in another class.

(ii)Less Code Duplication :Common properties and methods need not be written again.

(iii)Easy Maintenance : Changes in common functionality can be managed in the parent class.

(iv)Method Overriding : A child class can provide its own implementation of a parent method.

(v)Supports Polymorphism : Inheritance is an important foundation for runtime polymorphism.

(vi) Better Organization : Related classes can be organized into a hierarchy.

Q2

Explain the types of Inheritance?

Answer:Java supports different forms of inheritance through classes and interfaces.

(i)Single Inheritance:When one child class inherits from one parent class, it is called Single Inheritance.

(ii) Multilevel Inheritance:When a class inherits from another class, and a third class inherits from the second class, it is called Multilevel Inheritance.

(iii)Hierarchical Inheritance:When multiple child classes inherit from the same parent class, it is called Hierarchical Inheritance.

(iv) Multiple Inheritance:Multiple inheritance means a class inherits from more than one parent class. Java does not support multiple inheritance through classes.

For example, Java does not allow: class C extends A, B { }

This is because it can create ambiguity when both parent classes contain methods with the same name. However, Java can achieve multiple inheritance of type through interfaces.

(v)Hybrid Inheritance: Hybrid inheritance is a combination of two or more types of inheritance. Java does not support hybrid inheritance directly through classes because it can involve multiple inheritance. However, similar structures can be created using interfaces.

Explian the extends and super keyword?

Answer:
extends :-The extends keyword is used when one class inherits another class.

super :- The super keyword is used to refer to the immediate parent class.

It can be used to:

Q4

What is Method Overriding?

Answer: When a child class provides its own implementation of a method that is already defined in the parent class, it is called Method Overriding.

Q5

Write the diffrence betrween Inheritance and Encapsulation?

Answer:The diffrence betrween Inheritance and Encapsulation are :-

Inheritance :

  • Used to acquire properties and methods from another class
  • Promotes code reuse
  • Uses extends for class inheritance
  • Represents an "is-a" relationship

Encapsulation :

  • Used to hide and control access to data
  • Promotes data protection
  • Commonly uses private fields with methods
  • Represents controlled access to an object's data
