Practical No. 02

Aim: To design a Java program to create a bank account using inheritance and static and perform banking operations such as deposit , withdraw and display account details.

🖥️ Requirements

  • Computer or Laptop
  • Java Development Kit (JDK)
  • Java IDE (BlueJ, Eclipse, or NetBeans) or Notepad
  • Java Compiler and JVM

    • Theory

  • Inheritance is a feature of java in which one class acquires the properties and methods of another class.

  • A static member belongs to the class rather than an individual object. It can be accessed using the class name.

    • In this program,

  • Account is the parent class.

  • savingAccount inherits the Account class.

  • bankName is a static variable.

  • User can perform deposit , withdraw and Account Details operations are perform.
