Q1

What is Object-Oriented Programming? How is it different from Procedure-Oriented Programming?

Object-Oriented Programming (OOP) is a programming paradigm in which a program is designed using objects and classes. An object contains data (properties) and methods (functions) that operate on that data.

The main concepts of OOP are Encapsulation, Inheritance, Polymorphism and Abstraction.

The difference between OOP and Procedure-Oriented Programming is given below:

OOP
  • Program is organized around objects and classes.
  • Data and methods are combined together.
  • Supports encapsulation and data hiding.
  • Supports inheritance and polymorphism.
  • Examples: Java, C++, C#
Procedure-Oriented Programming
  • Program is organized around functions or procedures.
  • Data and functions are generally separate.
  • Provides comparatively less data security.
  • Does not directly support these OOP features.
  • Examples: C, Pascal
Q2

What are the unique advantages of Object-Oriented Programming?

The most important advantages of OOP are:

(i) Reusability: Existing classes can be reused through inheritance.

(ii) Data Security: Encapsulation helps protect data from unauthorized access.

(iii) Modularity: A large program can be divided into smaller classes and objects.

(iv) Easy Maintenance: Changes can be made to individual classes without affecting the entire program.

(v) Flexibility: Polymorphism allows the same method or interface to behave differently in different situations.

(vi) Abstraction: Unnecessary implementation details can be hidden from the user.

(vii) Easy Testing and Debugging: Individual classes can be tested separately.

(viii) Reduced Code Duplication: Reusable classes and methods reduce repeated code.

Q3

Distinguish between the following:

(i) Object and Class
Object
  • An object is an instance of a class.
  • It uses the properties and methods defined by the class.
  • It represents a particular entity.
  • Example: Student S1
Class
  • A class is a blueprint or template.
  • It defines properties and methods.
  • It does not represent a particular entity by itself.
  • Example: Student

Example: 

class Student {
    String name;
}

Student S1 = new Student();

Here, Student is a class and S1 is an object.

(ii) Data Abstraction and Data Encapsulation
Data Abstraction
  • It means hiding unnecessary implementation details.
  • It focuses on what an object does.
  • It can be achieved using abstract classes and interfaces.
  • Example: Using an ATM without knowing its internal working.
Data Encapsulation
  • It means wrapping data and methods together in a single unit.
  • It focuses on how data is protected and accessed.
  • It is commonly achieved using classes and access modifiers such as private.
  • Example: Keeping a bank account balance private and accessing it through methods.
(iii) Inheritance and Polymorphism
Inheritance
  • It allows one class to acquire properties and methods of another class.
  • It provides code reusability.
  • It represents an IS-A relationship.
  • Example: Dog inherits from Animal.
Polymorphism
  • It means "many forms".
  • It provides flexibility in program behavior.
  • It allows the same method or interface to have different behavior.
  • Example: The same sound() method behaves differently for Dog and Cat.

Example: 

class Animal {
    void sound() {
        System.out.println("Animal Sound");
    }
}

class Dog extends Animal {
    void sound() {
        System.out.println("Bark");
    }
}

Here, Dog uses inheritance, while the different implementation of sound() demonstrates polymorphism.

(iv) Dynamic Binding and Message Passing
Dynamic Binding
  • The method to be executed is determined at runtime.
  • It is mainly associated with runtime polymorphism.
  • The actual object determines which overridden method will execute.
  • Example: Overridden method selection at runtime.
Message Passing
  • Objects communicate with each other by calling methods.
  • It is a way of communication between objects.
  • One object sends a request to another object through a method call.
  • Example: student.display() sends a request to the student object.
Q4

Why is Java known as a platform-neutral language?

Java is called a platform-neutral language because Java programs can run on different operating systems without changing the original source code.

Java source code is compiled by the Java compiler into bytecode. This bytecode is not directly dependent on a particular operating system or processor.

The bytecode runs on the Java Virtual Machine (JVM).

The process is: 

Java Source Code
        ↓
Java Compiler
        ↓
Bytecode
        ↓
JVM
        ↓
Operating System

Therefore, Java follows the principle "Write Once, Run Anywhere (WORA)".

Example: The same Java bytecode can run on Windows, Linux or macOS if a suitable JVM is installed.

Q5

How is Java more secure than other languages?

Java provides several features that improve security.

(i) No Direct Pointer Manipulation: Java does not allow programmers to directly manipulate memory addresses like C/C++.

(ii) Bytecode Verification: JVM verifies bytecode before execution.

(iii) Automatic Memory Management: Java uses garbage collection, reducing certain memory-management errors.

(iv) Access Control: Java provides access modifiers such as private, protected and public.

(v) Exception Handling: Java provides mechanisms to handle runtime errors safely.

(vi) Runtime Checking: JVM performs various checks during program execution.

(vii) Strong Type Checking: Java checks data types carefully, reducing many programming errors.

Q6

How is Java strongly associated with the Internet?

Java became strongly associated with the Internet because it was designed with portability, networking and security in mind.

Important reasons are:

(i) Platform Independence: Java programs can run on different operating systems using the JVM.

(ii) Networking Support: Java provides built-in networking classes for communication over networks and the Internet.

(iii) Security: Java provides features such as bytecode verification and controlled access to system resources.

(iv) Web Application Development: Java is widely used for developing server-side web applications and enterprise software.

(v) Distributed Applications: Java supports the development of applications that communicate over a network.

(vi) Rich Libraries: Java provides APIs for networking, databases, web servers and other Internet-related applications.

Therefore, Java has been widely used for web applications, server applications, enterprise systems, APIs and network-based software.
