Computer Programming Using C

Practical No. 3

Aim: To draw a flowchart using MS Word, Draw.io or any other suitable flowchart editor.

🖥️ Requirements

Computer system, C compiler/IDE and suitable text editor.

📌 Purpose

To understand and practically implement the concepts covered in this experiment.

Introduction

A flowchart is a graphical representation of an algorithm or process. Common symbols are Oval for Start/Stop, Parallelogram for Input/Output, Rectangle for Processing, Diamond for Decision and Arrow for flow direction.

Procedure

01

Step 1

Open MS Word, Draw.io or another flowchart application.

02

Step 2

Select the required flowchart shapes.

03

Step 3

Start the flowchart with the Start symbol.

04

Step 4

Add input, processing and decision symbols as required.

05

Step 5

Connect all symbols using arrows.

06

Step 6

End the flowchart using the Stop symbol.

07

Step 7

Save the completed flowchart.

⚠️ Precautions

  • Use correct C syntax and suitable data types.
  • Compile the program and correct errors before execution.
  • Observe and verify the output carefully.

✅ Result

The required flowchart was successfully designed using a flowchart editor.
