Aim: To demonstrate pointers by printing a variable address and swapping two variables using pointers.

🖥️ Requirements

📌 Purpose

Introduction

A pointer stores the memory address of another variable. The address-of operator obtains an address and the dereference operator accesses the value stored at that address.
