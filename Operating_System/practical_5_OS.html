Practical No. 5

Aim: Simulate the concept of Dining Philosopher Algorithm.

🖥️ Requirements

Personal Computer or Laptop, C compiler (Turbo C++ or Visual Studio Code with C extension).

📌 Purpose

To simulate the Dining Philosopher Problem and understand the four necessary conditions of deadlock and how deadlock can be avoided by making at least one of these conditions false.

Introduction

The Dining Philosopher Problem is a classical problem in Operating Systems used to understand process synchronization, resource sharing and deadlock.


In this problem, five philosophers sit around a dining table and each philosopher requires two forks to eat. The problem demonstrates how processes can enter a deadlock condition when they hold one resource and wait for another resource.

Procedure

01

Dining Philosopher Problem

The program simulates the Dining Philosopher Problem using five philosophers and five forks. Each philosopher has a left fork and a right fork.

02

Display Philosophers

The program displays five philosophers: P1, P2, P3, P4 and P5.

03

Display Forks

The program displays five forks: F1, F2, F3, F4 and F5.

04

Assign Left and Right Forks

The philosophers use the following forks:

  • Philosopher P1: F1 left and F5 right
  • Philosopher P2: F2 left and F1 right
  • Philosopher P3: F3 left and F2 right
  • Philosopher P4: F4 left and F3 right
  • Philosopher P5: F5 left and F4 right
05

Mutual Exclusion Condition

Fork is a non-shareable device because a fork can be used by only one philosopher at a time. Therefore, the mutual exclusion condition exists.

06

Hold and Wait Condition

Each philosopher holds one fork and waits for another fork.

  • P1 holds F1 and waits for F5.
  • P2 holds F2 and waits for F1.
  • P3 holds F3 and waits for F2.
  • P4 holds F4 and waits for F3.
  • P5 holds F5 and waits for F4.
07

No Preemption Condition

Once a philosopher picks up a fork, another philosopher cannot take it away even if the second philosopher needs it.

08

Circular Wait Condition

A circular waiting condition is formed because every philosopher holds one fork and waits for the next fork.

  • P1 uses F1 and waits for F5.
  • P2 uses F2 and waits for F1.
  • P3 uses F3 and waits for F2.
  • P4 uses F4 and waits for F3.
  • P5 uses F5 and waits for F4.
09

Deadlock Avoidance

Deadlock can be avoided if any one of the four necessary conditions is made false.

In this example, the mutual exclusion condition can be made false by considering the fork as a shareable device. After one philosopher finishes eating, the fork can be rinsed in the glass of water on the dining table and used again.

10

C Program

The following C program displays the philosophers, forks, the four deadlock conditions and the deadlock avoidance concept.

c 
#include <stdio.h>

int main(){

    // Dining-Philosopher Problem

    printf("Dining-Philosopher Problem by Kadir Alam\n");

    printf("Deadlock condition : 4 condition\n");

    for(int i = 1; i <= 5; i++){
        printf("Philosopher:P%d\n", i);
    }

    for(int i = 1; i <= 5; i++){
        printf("Fork:F%d\n", i);
    }

    printf("Philosopher P1 : F1 left and F5 right\n");
    printf("Philosopher P2 : F2 left and F1 right\n");
    printf("Philosopher P3 : F3 left and F2 right\n");
    printf("Philosopher P4 : F4 left and F3 right\n");
    printf("Philosopher P5 : F5 left and F4 right\n");

    printf("1. Mutual condition (Non-shareable device): "
           "fork is not sharable, because fork is already using.\n");

    printf("2. Hold and Wait:\n");

    printf("Philosopher P1 : Hold F1 left and Wait F5 right\n");
    printf("Philosopher P2 : Hold F2 left and Wait F1 right\n");
    printf("Philosopher P3 : Hold F3 left and Wait F2 right\n");
    printf("Philosopher P4 : Hold F4 left and Wait F3 right\n");
    printf("Philosopher P5 : Hold F5 left and Wait F4 right\n");

    printf("3. No Preemption:\n");

    printf("Once a philosopher picks up a fork, "
           "other cannot snatch it even if they need it.\n");

    printf("4. Circular Wait:\n");

    printf("Philosopher P1 : Use F1 left and Wait F5 right\n");
    printf("Philosopher P2 : Use F2 left and Wait F1 right\n");
    printf("Philosopher P3 : Use F3 left and Wait F2 right\n");
    printf("Philosopher P4 : Use F4 left and Wait F3 right\n");
    printf("Philosopher P5 : Use F5 left and Wait F4 right\n");

    printf("Deadlock avoidance : any one condition is false\n");

    printf("Fork is sharable device because on the dining table "
           "there is one glass of water.\n");

    printf("After eating one philosopher will rinse (wash) the fork "
           "in that glass and use it again.\n");

    printf("(Mutual Condition is false.)\n");

    return 0;
}

⚠️ Precautions

  • Enter the program correctly in the C compiler.
  • Make sure that the C compiler is properly installed before executing the program.
  • Check the program for syntax errors before compilation.
  • Understand the four necessary conditions of deadlock before explaining the output.
  • Do not confuse deadlock avoidance with simply terminating a process.

✅ Result

The Dining Philosopher Problem was successfully simulated using a C program. The four necessary conditions of deadlock—Mutual Exclusion, Hold and Wait, No Preemption and Circular Wait—were studied, and the concept of deadlock avoidance was understood.
