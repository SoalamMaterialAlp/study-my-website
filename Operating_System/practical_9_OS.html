Practical No.-9

Aim: Write a program to simulate disk scheduling algorithms: (a) FCFS (b) SCAN (c) C-SCAN.

🖥️ Requirements

Personal Computer or Laptop, C Compiler (Turbo C++ or Visual Studio Code with extension).

📌 Purpose

To understand and simulate different disk scheduling algorithms and calculate the total and average seek time.

Introduction

Disk scheduling is a technique used by the operating system to determine the order in which disk I/O requests are serviced. The main purpose of disk scheduling is to reduce disk head movement and improve disk performance.


In this practical, three disk scheduling algorithms are simulated: FCFS, SCAN and C-SCAN. Each algorithm follows a different method for servicing disk requests.


Disk Scheduling Algorithms

  • FCFS: Requests are serviced in the same order in which they arrive.
  • SCAN: The disk head moves in one direction, services requests and then reverses its direction.
  • C-SCAN: The disk head moves in one direction and, after reaching the end, returns to the beginning and continues servicing requests.

Procedure

01

Enter Disk Requests

Enter the number of disk requests and enter the disk request sequence.

02

Enter Initial Head Position

Enter the initial position of the disk head from where the disk scheduling operation will start.

03

FCFS Disk Scheduling

In FCFS, the disk requests are serviced in the same order in which they are entered. The movement of the disk head is calculated for every request.

04

SCAN Disk Scheduling

In SCAN, the disk head moves in the selected direction, services all suitable requests and reaches the disk end. After that, it reverses direction and services the remaining requests.

05

C-SCAN Disk Scheduling

In C-SCAN, the disk head moves in one direction and services the requests. After reaching the disk end, it jumps back to the beginning and continues servicing the remaining requests.

06

Calculate Seek Time

Calculate the movement of the disk head for each request and add all movements to obtain the total seek time.

07

Calculate Average Seek Time

Calculate the average seek time using the total seek time and the number of disk requests.

08

Display Request Sequence

Display the order in which the disk requests are serviced by each scheduling algorithm.

09

Display Result

Display the total seek time and average seek time obtained from the selected disk scheduling algorithm.

(a) FCFS Disk Scheduling Algorithm

FCFS (First Come First Serve) services disk requests in the same order in which they arrive.

C 

#include <stdio.h>
#include <stdlib.h>

int main() {

    int n, head, i, total = 0;

    printf("FCFS disk scheduling algorithm performed by Kadir Alam\n");

    printf("Enter number of disk requests: ");
    scanf("%d", &n);

    int req[n];

    printf("Enter the disk request sequence:\n");

    for(i = 0; i < n; i++)
        scanf("%d", &req[i]);

    printf("Enter the initial head position: ");
    scanf("%d", &head);

    printf("Seek Sequence is\n");

    for(i = 0; i < n; i++) {
        printf("%d\n", req[i]);
    }

    printf("\nMovement of Disk Head:\n");

    for(i = 0; i < n; i++) {

        printf(
            "Head moves from %d to %d -> Seek: %d\n",
            head,
            req[i],
            abs(head - req[i])
        );

        total += abs(head - req[i]);

        head = req[i];
    }

    printf("\nTotal Seek Time = %d\n", total);

    printf(
        "Average Seek Time = %.2f\n",
        (float)total / n
    );

    return 0;
}

(b) SCAN Disk Scheduling Algorithm

SCAN is also known as the Elevator Algorithm. The disk head moves in one direction, services the requests and then reverses its direction.

C 

#include <stdio.h>
#include <stdlib.h>

int main() {

    int n, head, size, direction, total = 0;

    printf("SCAN disk scheduling Algorithm performed by Kadir Alam\n");

    printf("Enter number of disk requests: ");
    scanf("%d", &n);

    int req[n];

    printf("Enter the disk request sequence:\n");

    for(int i = 0; i < n; i++)
        scanf("%d", &req[i]);

    printf("Enter initial head position: ");
    scanf("%d", &head);

    printf("Enter range/size disk(e.g., 200): ");
    scanf("%d", &size);

    printf("Enter direction (1 = RIGHT, 0 = LEFT): ");
    scanf("%d", &direction);


    // Sort requests

    for(int i = 0; i < n - 1; i++)

        for(int j = i + 1; j < n; j++)

            if(req[i] > req[j]) {

                int temp = req[i];

                req[i] = req[j];

                req[j] = temp;
            }


    // Find index where head fits

    int index = 0;

    for(int i = 0; i < n; i++)

        if(req[i] >= head) {

            index = i;

            break;
        }


    int order[200], k = 0;


    printf("\nSCAN Disk Movement:\n");


    if(direction == 1) {

        // RIGHT

        for(int i = index; i < n; i++) {

            printf(
                "Head moves from %d to %d  Seek = %d\n",
                head,
                req[i],
                abs(head - req[i])
            );

            total += abs(head - req[i]);

            head = req[i];

            order[k++] = head;
        }


        printf(
            "Head moves from %d to %d (Disk End) Seek = %d\n",
            head,
            size,
            abs(head - size)
        );

        total += abs(head - size);

        head = size;


        for(int i = index - 1; i >= 0; i--) {

            printf(
                "Head moves from %d to %d  Seek = %d\n",
                head,
                req[i],
                abs(head - req[i])
            );

            total += abs(head - req[i]);

            head = req[i];

            order[k++] = head;
        }

    }

    else {

        // LEFT

        for(int i = index - 1; i >= 0; i--) {

            printf(
                "Head moves from %d to %d  Seek = %d\n",
                head,
                req[i],
                abs(head - req[i])
            );

            total += abs(head - req[i]);

            head = req[i];

            order[k++] = head;
        }


        printf(
            "Head moves from %d to 0 (Disk Start) Seek = %d\n",
            head,
            head
        );

        total += head;

        head = 0;


        for(int i = index; i < n; i++) {

            printf(
                "Head moves from %d to %d  Seek = %d\n",
                head,
                req[i],
                abs(head - req[i])
            );

            total += abs(head - req[i]);

            head = req[i];

            order[k++] = head;
        }
    }


    printf("\n=== SCAN Request Order ===\n");

    for(int i = 0; i < k; i++) {

        if(i == k - 1)
            printf("%d\n", order[i]);

        else
            printf("%d ", order[i]);
    }


    printf("\n\nTotal Seek Time = %d\n", total);

    printf(
        "\nAverage Seek Time = %.2f\n",
        (float)total / n
    );

    return 0;
}

(c) C-SCAN Disk Scheduling Algorithm

C-SCAN (Circular SCAN) moves the disk head in one direction. After reaching the disk end, the head returns to the beginning and continues servicing the remaining requests.

C 

#include <stdio.h>
#include <stdlib.h>

int main() {

    int n, head, size, total = 0;

    printf("C-SCAN Disk Scheduling Algorithm performed by Kadir Alam\n");

    printf("Enter number of disk requests: ");
    scanf("%d", &n);

    int req[n];

    printf("Enter the disk request sequence:\n");

    for(int i = 0; i < n; i++)
        scanf("%d", &req[i]);

    printf("Enter initial head position: ");
    scanf("%d", &head);

    printf("Enter disk end cylinder number (e.g., 200): ");
    scanf("%d", &size);


    // Sort the requests

    for(int i = 0; i < n - 1; i++)

        for(int j = i + 1; j < n; j++)

            if(req[i] > req[j]) {

                int temp = req[i];

                req[i] = req[j];

                req[j] = temp;
            }


    // Find where head fits

    int index = 0;

    for(int i = 0; i < n; i++) {

        if(req[i] >= head) {

            index = i;

            break;
        }
    }


    int order[200], k = 0;


    printf("\nC-SCAN Head Movement:\n");


    // Move RIGHT first

    for(int i = index; i < n; i++) {

        printf(
            "Head moves from %d to %d  Seek = %d\n",
            head,
            req[i],
            abs(head - req[i])
        );

        total += abs(head - req[i]);

        head = req[i];

        order[k++] = head;
    }


    // Move to disk END

    printf(
        "Head moves from %d to %d (Disk End) Seek = %d\n",
        head,
        size,
        abs(head - size)
    );

    total += abs(head - size);

    head = size;


    // Jump to 0

    printf(
        "Head jumps from %d to 0 (No Seek Count)\n",
        head
    );

    head = 0;


    // Move again from start

    for(int i = 0; i < index; i++) {

        printf(
            "Head moves from %d to %d  Seek = %d\n",
            head,
            req[i],
            abs(head - req[i])
        );

        total += abs(head - req[i]);

        head = req[i];

        order[k++] = head;
    }


    // Print Request Order

    printf("\n=== C-SCAN Request Order ===\n");

    for(int i = 0; i < k; i++) {

        if(i == k - 1)
            printf("%d\t", order[i]);

        else
            printf("%d ", order[i]);
    }


    printf("\n\nTotal Seek Time = %d\n", total);

    printf(
        "Average Seek Time = %.2f\n",
        (float)total / k
    );

    return 0;
}
