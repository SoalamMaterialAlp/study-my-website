Practical No. 3

Aim: Use Task Manager to monitor and terminate process. Understand process priorities.

🖥️ Requirements

Personal Computer or Laptop.

📌 Purpose

To use Task Manager to monitor running applications and processes, check CPU, Memory, Disk and Network usage, and terminate unnecessary applications or processes.

Introduction

Task Manager is a Windows system utility used to monitor the applications and processes running on a computer. It provides information about system resources such as CPU, Memory, Disk and Network usage.


Task Manager can also be used to terminate applications and processes that are not responding or are unnecessarily using system resources. It helps the user to understand the current state of the system and manage running processes.

Procedure

01

Start Personal Computer or Laptop

Start the personal computer or laptop and wait until the Windows operating system is completely loaded.

02

Open Task Manager

Go to the taskbar and click the right mouse button. From the available options, select Task Manager and click on it.

Figure 1: Task Manager

03

View Running Applications and Processes

Open Task Manager. You will see running apps and background running processes. Different columns such as CPU, Memory, Disk and Network display the system resource usage.

Figure 2: Running Apps and Background Processes

04

Select the Application or Process

To terminate any application or background process, select the required application or process from the Task Manager list.

05

End the Task

Right-click on the selected application or process and select the End task option.

06

Stop the Application or Process

After clicking the End task option, the selected application or process will stop running.

07

Monitor CPU and Memory Usage

Observe the CPU and Memory usage in Task Manager. If the system is using high CPU or Memory, identify the applications or processes that are consuming more system resources.

08

Terminate Unnecessary Applications or Processes

Select the unnecessary application or process and use the End task option to stop it.

09

Check System Usage Again

After terminating the unnecessary applications or processes, check the CPU and Memory usage again. Observe whether the system resource usage has reduced.

⚠️ Precautions

  • Do not terminate unknown system processes.
  • Do not terminate critical Windows system processes without knowing their purpose.
  • Example: csrss.exe is a critical system process. Killing this process can crash Windows or log you out.
  • If you are unsure about a process, search online for reliable information before ending the task.
  • Save important work before terminating an application.

✅ Result

The Task Manager was successfully opened and used to monitor system usage such as CPU, Memory, Disk and Network. Unnecessary applications or processes were terminated using the End task option. After terminating the unnecessary processes, the system resource usage was checked again.
