Aim: Simulate Banker Algorithm for Deadlock Avoidance and Prevention.

🖥️ Requirements

Personal Computer or Laptop, C Compiler (Turbo C++ or Visual Studio Code with C extension).

📌 Purpose

To simulate the Banker Algorithm and understand how resources are allocated safely to processes to avoid deadlock.

Introduction

The Banker Algorithm is a deadlock avoidance algorithm used in Operating Systems. It checks whether allocating resources to a process will keep the system in a safe state.


Before allocating resources, the algorithm checks the available resources, allocated resources, demand of each process and remaining need. If the system remains in a safe state, resources are allocated; otherwise, the process waits.

Procedure

01

Start the Program

Start the computer and open a C compiler such as Turbo C++ or Visual Studio Code with the C extension.

02

Enter Number of Processes

The program asks the user to enter the number of processes that will participate in resource allocation.

03

Enter Total Resources

Enter the total available resources RA, RB and RC. These represent three different types of resources.

04

Enter Allocated Resources

Enter the number of resources currently allocated or held by every process.

The program stores the allocated resources as HRA, HRB and HRC.

05

Enter Available Resources

Enter the currently available resources ARA, ARB and ARC.

06

Enter Resource Demand

Enter the resources demanded or required by each process. The values are stored in DRA, DRB and DRC.

07

Calculate Need

The remaining need of every process is calculated using the formula:

Need = Demand − Allocation

The calculated values are stored in needA, needB and needC.

08

Check Safe Sequence

The algorithm checks whether the remaining need of a process is less than or equal to the available resources.

If the condition is satisfied, the process executes and its allocated resources are released back to the available resources.

09

Display Safe State

If all processes can finish successfully, the system is declared to be in a SAFE state and the safe sequence is displayed.

If one or more processes cannot finish, the system is declared to be NOT in a safe state.

10

Banker's Algorithm C Program

The following C program simulates the Banker Algorithm and checks whether the system is in a safe state.

c 
#include <stdio.h>

int main() {

    int n, i;

    printf("Banker Algorithm by Kadir Alam\n");

    printf("Enter number of processes: ");
    scanf("%d", &n);

    /*
       RA, RB, RC = Total resources
       ARA, ARB, ARC = Available resources
       HRA, HRB, HRC = Resources allocated/held
       DRA, DRB, DRC = Demand resources
    */

    int RA, RB, RC;
    int ARA, ARB, ARC;

    int pid[n];

    int HRA[n], HRB[n], HRC[n];
    int DRA[n], DRB[n], DRC[n];

    int needA[n], needB[n], needC[n];

    int f[n], ans[n], ind = 0;


    /* Total Resources */

    printf("Resource instance provided by Kadir Alam\n");

    printf("Total Resources RA available are: ");
    scanf("%d", &RA);

    printf("Total Resources RB available are: ");
    scanf("%d", &RB);

    printf("Total Resources RC available are: ");
    scanf("%d", &RC);


    /* Allocated / Held Resources */

    printf("How many Resources allocated/hold by process:- ");

    for(i = 0; i < n; i++) {

        pid[i] = i;

        printf("\nEnter resources RA of P%d: ", i);
        scanf("%d", &HRA[i]);

        printf("Enter resources RB of P%d: ", i);
        scanf("%d", &HRB[i]);

        printf("Enter resources RC of P%d: ", i);
        scanf("%d", &HRC[i]);
    }


    /* Display Allocation Table */

    printf("\nPID\tRA\tRB\tRC\n");

    for(i = 0; i < n; i++) {

        printf("P%d\t%d\t%d\t%d\n",
               pid[i],
               HRA[i],
               HRB[i],
               HRC[i]);
    }


    /* Available Resources */

    printf("\nNow, available resources RA, RB, RC are:- ");

    scanf("%d %d %d", &ARA, &ARB, &ARC);


    /* Resource Demand */

    printf("How many Resources demand/wait by process:- ");

    for(i = 0; i < n; i++) {

        pid[i] = i;

        printf("\nEnter resources RA of P%d: ", i);
        scanf("%d", &DRA[i]);

        printf("Enter resources RB of P%d: ", i);
        scanf("%d", &DRB[i]);

        printf("Enter resources RC of P%d: ", i);
        scanf("%d", &DRC[i]);
    }


    /* Display Demand Table */

    printf("\nPID\tRA\tRB\tRC\n");

    for(i = 0; i < n; i++) {

        printf("P%d\t%d\t%d\t%d\n",
               pid[i],
               DRA[i],
               DRB[i],
               DRC[i]);
    }


    /* Need Calculation */

    for(i = 0; i < n; i++) {

        needA[i] = DRA[i] - HRA[i];
        needB[i] = DRB[i] - HRB[i];
        needC[i] = DRC[i] - HRC[i];
    }


    /* Print Need Table */

    printf("\nProcess\tAlloc(RA RB RC)\tDemand(RA RB RC)\tNeed(RA RB RC)\n");

    for(i = 0; i < n; i++) {

        printf("P%d\t%d %d %d\t\t%d %d %d\t\t%d %d %d\n",
               i,
               HRA[i], HRB[i], HRC[i],
               DRA[i], DRB[i], DRC[i],
               needA[i], needB[i], needC[i]);
    }


    /* Initialize Finish Array */

    for(i = 0; i < n; i++) {
        f[i] = 0;
    }


    /* Safe Sequence Calculation */

    int k;

    for(k = 0; k < n; k++) {

        for(i = 0; i < n; i++) {

            if(f[i] == 0) {

                if(needA[i] <= ARA &&
                   needB[i] <= ARB &&
                   needC[i] <= ARC) {

                    /* Process executes */

                    ARA += HRA[i];
                    ARB += HRB[i];
                    ARC += HRC[i];

                    ans[ind++] = i;

                    f[i] = 1;
                }
            }
        }
    }


    /* Final Safe State Check */

    int safe = 1;

    for(i = 0; i < n; i++) {

        if(f[i] == 0) {

            safe = 0;

            printf("\nSystem is NOT in safe state!\n");

            break;
        }
    }


    /* Display Result */

    if(safe == 1) {

        printf("\nSystem is in SAFE state.\n");

        printf("Safe Sequence: ");

        for(i = 0; i < n - 1; i++) {

            printf("P%d -> ", ans[i]);
        }

        printf("P%d\n", ans[n - 1]);
    }


    return 0;
}
11

Deadlock Avoidance

Banker's Algorithm keeps the system in a safe state. Before allocating resources, it checks whether the system will remain safe after allocation.

If the system is in a safe state, resources are given. Otherwise, the process waits, thus avoiding deadlock.

12

Deadlock Prevention

If a resource is not available, the process is stopped or made to wait until the resource becomes free.

⚠️ Precautions

  • Enter the number of processes correctly.
  • Enter valid values for total, allocated, available and demanded resources.
  • Make sure that the C compiler is properly installed.
  • Check the program for syntax errors before execution.
  • Carefully calculate the Need matrix as Demand − Allocation.
  • Do not use negative resource values.
