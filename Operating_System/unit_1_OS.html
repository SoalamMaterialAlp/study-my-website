UNIT :- 1 OVERVIEW OF OPERATING SYSTEM

Software:-

A Software is a set of instructions data or programs used to operare computers and perform specific tasks. Software can be broadly classified into two main categories:- System Software Application Software.


Introduction of Operating Software:-
Operating System:
  • An Operating System (OS) is system software that acts as a bridge between the user and the computer hardware.
  • It manages hardware resources (CPU, memory, I/O devices) and provides an environment where applications can run.
  • Without an OS, you would need to directly communicate with hardware in machine language, which is very difficult.
  • Responsible for managing and controlling all the activities and sharing of computer resources among different running applications.
  • A low-level Software that includes all the basic functions like processor management, memory management, file management, etc.
  • It mainly acts a government for your system that has different departments to manage different resources.
  • Examples are Linux, Unix, Windows 11, MS DOS, Android, macOS and iOS.

TYPES OF OPERATING SYSTEM: -

There are several types of Operating Systems (OS), depending on how they manage processes, users, and tasks. The main types are:


  1. Batch Operating System
  2. Multi-Programming Operating System
  3. Time-Sharing /Multi-Tasking Operating System
  4. Multi-Processing Operating System
  5. Distributed Operating System
  6. Network Operating System
  7. Real-Time Operating System
  8. Mobile Operating System

Functions and Services of an Operating System (OS)
The Operating System is the interface between computer hardware and users/applications. It performs functions and provides services to make the computer system easy to use and efficient.


1.Batch Operating System:-
  • Executes jobs in batches (grouped together).
  • No direct interaction with users.
  • Used in early computers (e.g., punch cards)
  • A Batch Operating System is one of the oldest types of OS.
  • In this system, similar jobs are grouped (batched) together and executed one after another without user interaction. Users prepare their jobs (program + data) on punched cards or magnetic tapes and submit them to the computer operator. The OS collects jobs in a batch and executes them sequentially.

Features of Batch Operating System:-
  • Jobs are executed in batches.
  • No direct interaction between user and computer.
  • The OS decides the order of job execution.
  • Output is given only after the whole batch is processed.

Advantages Of Batch Operating System:-
  • Easy to use in early computers.
  • Processes similar jobs together → saves time.
  • CPU utilization is improved compared to manual job execution.

Disadvantages of Batch Operating System:-
  • No interaction between user and job during execution.
  • If one job fails, the whole batch may stop.
  • Debugging is difficult (errors are known only after completion).

Examples of Batch Operating System:-
  • Early IBM Mainframe OS.
  • Punch card–based systems.

Batch Operating System

2.Multi-Programming Operating System: -

A Multiprogramming Operating System is a type of operating system that allows multiple programs to be loaded into memory and executed by the CPU at the same time. 👉 The main goal is to maximize CPU utilization by keeping it busy with some process at all times.


Explanation


  • In a single-program system, when one program waits (for example, for input/output operations like reading from disk), the CPU sits idle.
  • In multiprogramming, while one program is waiting, another program is executed by the CPU.
  • The operating system manages the jobs (programs) in memory and decides which one gets CPU time (scheduling).
  • A Multiprogramming OS keeps several programs in memory and executes them by switching the CPU between them. This ensures that the CPU is always busy, improving efficiency compared to single-program systems.
Features of Multi-Programming Operating System **
  • Multiple jobs in memory: More than one program is kept in main memory.
  • Efficient CPU utilization: CPU never remains idle while there is work to do.
  • Job scheduling: The OS uses scheduling algorithms to pick which process runs next.
  • Concurrency: Processes appear to run simultaneously, though the CPU executes one instruction at a time.
  • Better throughput: More jobs are completed in the same time compared to a single-program OS.
  • Need Single CPU for implementation.
  • Context switch between process.
  • Switching happens when current process undergoes waiting state.
  • CPU idle time is reduced.
  • High resource utilization.
  • High Performance.
**Advantages Of Multi-Programming Operating System **
  • High CPU utilization.
  • Increased system throughput.
  • Reduced idle time of CPU.
  • Efficient use of resources.
**Disadvantages of Multi-Programming Operating System **
  • Requires more memory (RAM).
  • Complex operating system design (process scheduling, memory management).
  • If one program needs a lot of CPU time, other jobs may wait longer (starvation possible).
  • Security and data protection are more difficult.

Time-Sharing Operating System/Multi-Tasking Operating System: -
  • Allows multiple users to share computer resources simultaneously.
  • CPU time is divided into small time slots.
  • A Time-Sharing OS allows multiple users to use the computer at the same time by sharing CPU time in small units (time slices).
  • The CPU switches rapidly between users/programs, giving the impression that all are running simultaneously.
  • This improves response time and allows interactive computing.
**Features of Time-Sharing Operating System **
  • Multi-user environment → many users work on the same system at once.
  • CPU scheduling → each job gets a small time slice (called quantum).
  • Interactive → users can interact directly with the computer.
  • Fairness → every job gets equal CPU share.
**Advantages Of Time-Sharing Operating System **
  • Efficient utilization of CPU and resources.
  • Faster response time to users.
  • No idle time — CPU switches jobs continuously.
  • Supports multiprogramming (many jobs in memory).
**Disadvantages of Time-Sharing Operating System **
  • Requires powerful CPU and large memory.
  • Complex OS design (for scheduling & resource allocation).
  • If many users, system performance may reduce.
**Examples of Time-Sharing Operating System **
  • UNIX
  • Linux (multiuser shells)
  • Multics
  • Modern Mainframes
Time-Sharing Operating System

Multi-Processing Operating System: -

Multiprocessing Operating System is an operating system that supports multiple processors (CPUs) working together in a single computer system. 👉 The main goal is to increase computing power, speed, and reliability by allowing processes to run in parallel on different processors.


** Explanation **
  • In a uniprocessor system, only one CPU executes instructions at a time.
  • In a multiprocessing system, two or more CPUs share the same main memory and are controlled by the operating system.
  • Each CPU can work on different processes simultaneously, which makes the system much faster and more efficient.
  • A Multiprocessing OS allows a computer to use two or more processors to perform tasks simultaneously, increasing speed, reliability, and efficiency compared to single-CPU systems.
**Types Of Multi-Processing Operating System * *
    **1. Symmetric Multi-Processing (SMP)**
  • All processors are equal and share the same memory.
  • Any processor can execute any process.
  • Example: Modern multi-core systems (quad-core, octa-core).
    **2. Asymmetric Multi-Processing (AMP)**
  • One processor is the master and controls the system.
  • Other processors are slaves and work on assigned tasks.
  • Simpler but less efficient than SMP.
**Features of Multi-Processing Operating System **
  • Parallel processing → multiple processes run at the same time.
  • Shared memory → processors communicate through common memory.
  • High reliability → if one CPU fails, others can still continue (fault tolerance).
  • Faster execution of tasks.
**Advantages Of Multi-Processing Operating System **
  • High performance → many processes execute simultaneously.
  • Better throughput → more jobs completed in less time.
  • High reliability → system can continue even if one CPU crashes.
  • Efficient resource utilization.
**Disadvantages of Multi-Processing Operating System **
  • Expensive hardware (multiple CPUs).
  • Complex OS design (synchronization, scheduling, memory management).
  • Communication overhead between CPUs.
  • Not all programs can be divided into parallel tasks.
**Examples of Multi-Processing Operating System **
  • Windows (modern version like window 10,11)
  • Linux (Ubuntu, Fedora, Red Hat)
  • UNIX
  • MacOS
  • Mainframe systems (IBM z/OS)
Multi-Processing Operating System

5.Distributed Operating System: -

Distributed Operating System is an OS that manages a group of independent computers and makes them appear to the users as a single system.
👉 In simple words:
• Many computers (nodes) are connected via a network.
• The OS coordinates them so that users feel they are working on one powerful computer, not multiple separate ones.


** Explanation **
  • Manages a group of independent computers as a single system.
  • Tasks are distributed across different machines.
  • Each computer in the network has its own CPU, memory, and storage.
  • The Distributed OS links them together and controls the distribution of tasks, files, and resources.
  • Tasks are divided among multiple computers to improve speed, reliability, and efficiency.
**Features of Distributed Operating System **
  • Resource sharing – Files, printers, data, and processors can be shared.
  • Transparency – Users don’t need to know where a file or program is stored; it looks like everything is on one system.
  • Concurrency – Many users can use the system at the same time.
  • Fault tolerance – If one machine fails, others continue working.
  • Scalability – Easy to add more computers to increase performance.
**Advantages Of Distributed Operating System **
  • High performance (tasks are executed in parallel).
  • Reliable (failure of one node doesn’t stop the whole system).
  • Better resource utilization (load balancing across computers).
  • Cost-effective (multiple smaller machines instead of one huge supercomputer).
**Disadvantages of Distributed Operating System **
  • Requires complex design and management.
  • Security can be challenging (since data is spread across machines).
  • Network dependency (if the network fails, system performance drops).
  • Debugging and troubleshooting are harder.
**Examples of Distributed Operating System **
  • Amoeba – Research-based distributed OS.
  • LOCUS – Early distributed UNIX system.
  • Google’s Android (partially distributed for apps and services).
  • Microsoft Azure, AWS, and Google Cloud (cloud-based distributed systems).
  • Modern cluster operating systems (used in supercomputers).
Distributed Operating System

6.Network Operating System: -

A Network Operating System is a type of operating system that manages network resources and allows computers connected over a network to communicate, share files, printers, applications, and other resources.
👉 In simple words:
It is the OS that runs on a server and provides services to client computers over a network (like LAN or WAN).
** Explanation **


  • In a standalone OS, a computer only manages its own resources.
  • In a Network OS, one or more computers act as servers, and others act as clients.
  • Runs on a server and manages networking functions.
  • Provides services like file sharing, printer access, communication.
  • The NOS provides file sharing, printer access, user management, and security across the network.
**Features of Network Operating System **
  • Centralized management – Users, files, and devices are controlled from a central server.
  • File and resource sharing – Printers, applications, and storage can be shared.
  • Security and access control – Only authorized users can access network resources.
  • Scalability – Easy to add new devices and users.
  • Reliability – Provides backup, fault tolerance, and recovery options.
  • Remote access – Users can log in and access the network from different locations.
**Advantages Of Network Operating System **
  • Centralized control of data and resources.
  • Better data security (with user authentication).
  • Easy file and resource sharing.
  • Supports remote access and collaboration.
**Disadvantages of Network Operating System **
  • Expensive (requires a dedicated server).
  • Server failure can stop the whole network.
  • Requires skilled administrators.
  • High maintenance cost.
**Examples of Network Operating System **
  • Microsoft Windows Server
  • UNIX/Linux (with network services enabled)
  • Novell NetWare (older NOS)
  • Mac OS X Server
7. Real-Time Operating System: -

A Real-Time Operating System is a type of OS that is designed to process data and respond immediately (within a guaranteed time limit).
👉 In simple words:
It is used in systems where delays cannot be tolerated, and tasks must be executed on time.
** Explanation **


  • Unlike general-purpose OS (like Windows or Linux) which focus on throughput, an RTOS focuses on fast and predictable response times.
  • Used in time-critical applications such as medical devices, flight control systems, robotics, and embedded systems.
**Types Of Real-Time Operating System**
    **1. Hard Real-Time Operating System**
  • Deadlines are strict.
  • If a task misses its deadline, the system fails.
  • Example: Flight control system, pacemakers.
    **2. Soft Real-Time Operating System**
  • Deadlines are important but not fatal if occasionally missed.
  • Example: Multimedia streaming, online gaming.
**Features of Real-Time Operating System **
  • Deterministic response – Guarantees task execution within a fixed time.
  • Priority scheduling – High-priority tasks always run first.
  • Small and efficient – Designed to run on limited hardware (embedded devices).
  • Multitasking with deadlines – Multiple tasks but each must meet its timing constraints.
  • Low latency – Quick switching between tasks.
**Advantages Of Real-Time Operating System **
  • Predictable and reliable performance.
  • Fast response time.
  • Ideal for mission-critical applications.
  • Efficient resource utilization.
**Disadvantages of Real-Time Operating System **
  • More expensive and complex than general OS.
  • Limited multitasking for non-critical tasks.
  • Requires specialized hardware sometimes.
**Examples of Real-Time Operating System **
  • VxWorks
  • RT Linux (Real-Time Linux)
  • QNX
  • Free RTOS
  • RTEMS
  • Scientific experiments, Medical Imaging systems
  • Industrial control systems; Weapon systems
  • Robots; Air traffic control systems
8.Mobile Operating System: -

A Mobile Operating System is a type of operating system that is specially designed to run on mobile devices such as smartphones, tablets, PDAs, and wearable devices. 👉 It manages mobile hardware and provides a platform for running mobile applications (apps).
** Explanation **


  • Just like a computer needs Windows/Linux/MacOS, a smartphone needs a mobile OS.
  • It controls basic device functions like touchscreen, camera, battery, calling, internet, Bluetooth, GPS, and app management.
  • Provides a user interface (UI) suitable for small screens and touch inputs.
**Features of Mobile Operating System **
  • Touchscreen support – Optimized for touch gestures (tap, swipe, zoom).
  • Connectivity – Wi-Fi, Bluetooth, 4G/5G, GPS.
  • App ecosystem – Supports installing apps from stores (Google Play, App Store).
  • Power management – Efficient battery usage.
  • Multitasking – Run multiple apps in the background.
  • Security – App permissions, encryption, and updates.
  • Mobile-specific services – SMS, calling, camera, sensors (accelerometer, gyroscope).
**Advantages Of Mobile Operating System **
  • Portable and user-friendly.
  • Supports a large variety of applications.
  • Strong connectivity features.
  • Optimized for battery and small hardware.
**Disadvantages of Mobile Operating System **
  • Limited resources compared to desktop OS.
  • Dependent on battery life.
  • Frequent updates required.
  • Security risks if apps are not trusted.
**Examples of Mobile Operating System **
  • Android (Google) → Most widely used mobile OS.
  • iOS (Apple) → Used in iPhones and iPads.
  • HarmonyOS (Huawei) → Alternative to Android in China.
  • Kai OS → Lightweight OS for feature phones.
  • Windows Mobile / Windows Phone (discontinued).
  • BlackBerry OS (discontinued).
** Functions of an Operating System **

    1. Process Management
  • Manages processes in the system.
  • Handles creation, scheduling, and termination of processes.
  • Ensures CPU allocation to processes efficiently.

    2.Memory Management
  • Manages primary memory (RAM).
  • Keeps track of used and free memory.
  • Allocates memory to processes and ensures protection.

    3.File Management
  • Organizes and manages files and directories.
  • Provides operations like create, read, write, delete, and backup.
  • Ensures security and access control.

    4.Device Management (I/O Management)
  • Manages input/output devices (keyboard, printer, disk).
  • Uses drivers to communicate with hardware.
  • Provides efficient and fair allocation of devices to processes.

    5.Security and Protection
  • Protects system resources from unauthorized access.
  • Ensures data integrity and user authentication.

    6.User Interface
  • Provides an interface for users to interact with the computer.
  • Can be Command Line Interface (CLI) or Graphical User Interface (GUI).

    7.Networking
  • Manages network connections and protocols.
  • Provides file sharing and communication over networks.

    8.Error Detection and Handling
  • Detects hardware and software errors.
  • Takes corrective actions to prevent system crash.

** Services Provided by Operating System **

    1. Program Execution
  • Loads and runs programs efficiently.
  • Provides support for concurrent execution.

    2. I/O Operations
  • Provides a standard interface for input/output devices.

    3. File System Manipulation
  • Allows applications to create, delete, read, write, and organize files.

    4. Communication Services
  • Enables inter-process communication (IPC) in the same or different machines.

    5. Error Detection
  • Continuously checks for hardware or software errors.

    6. Resource Allocation
  • Allocates CPU, memory, and I/O devices to processes in a fair manner.

    7. Security and Protection
  • Provides user authentication and access control.

Advantages of Operating System (OS):

    1. User-friendly interface
  • Provides GUI (Graphical User Interface) and CLI (Command Line Interface) to interact with the computer easily.

    2. Resource management
  • Efficiently manages CPU, memory, I/O devices, and storage among multiple programs.

    3. Multitasking
  • Allows running multiple programs at the same time (e.g., listening to music while browsing).

    4. Security & Access Control
  • Protects files, user accounts, and resources from unauthorized access.

    5. Error handling & stability
  • Detects errors and handles system failures to keep the system stable.

    6. Hardware abstraction
  • Hides hardware complexity; users don’t need to know hardware details to run applications.

    7. Communication
  • Provides networking features to connect and share resources (files, printers, internet).

    8. Support for application development
  • Offers system calls, APIs, and development environments for programmers.

Disadvantages of Operating System:

    1. Cost
  • Licensed OS (like Windows, macOS) can be expensive.

    2. Resource consumption
  • Modern OS needs high RAM, CPU, and storage; can slow down old computers.

    3. Complexity
  • Very complex to design, manage, and update.

    4. Security vulnerabilities
  • OS can be targeted by viruses, malware, and hackers.

    5. Compatibility issues
  • Some applications or hardware may not work with every OS.

    6. Regular updates needed
  • Requires frequent patches and updates for performance and security.

    7. System failure risk
  • A crash in the OS can stop the entire computer from working.

An OS makes computers easier, safer, and more efficient, but it also has drawbacks like high cost, security risks, and heavy resource usage.
