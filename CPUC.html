Detailed Course Content

Syllabus

UNIT 1: Introduction to Problem Solving:

Computational way of thinking, Flowchart and Algorithm, Variable, constant and Representation, Data Types,Keywords, Identifier.

UNIT 2: Operators & Expression :

Arithmetic, Relational, Logical and Bitwise Operators, Input, Output, Expressions, Data Type Casting

UNIT 3: Conditional & Looping Statments:

if, if-else, if-else ladder, switch–case, break and continue, Loops: for, while and Do-while and Nested Loops.

UNIT 4: Arrays & String :

Introduction to Arrays, Array Declaration, Length of array, Manipulating array elements, Single and Multidimensional Array, Arrays of characters, Introduction of Strings, String declaration and definition, String Related function i.e. strlen, strcpy, strcmp,.

UNIT 5: Function & Ponter:

Introduction to functions, Global and Local Variables, Function Declaration, Function Call and Return, Types of Functions, Standard functions, Introduction to Pointer, Parameters and Parameter Passing, Call-by value/reference, recursive function, I/O and Formatting

Important Topics

Exam Focus

CPU Scheduling

FCFS, SJF, Round Robin and Priority scheduling.

Deadlock

Avoidance, prevention and Banker's Algorithm.

Page Replacement

FIFO, LRU and OPTIMAL algorithms.

Memory Allocation

First Fit, Best Fit and Worst Fit.

Disk Scheduling

FCFS, SCAN and C-SCAN algorithms.

File Allocation

Sequential, Indexed and Linked allocation.

Practical / Experiments

12 Experiments
01

Installation of C Compiler

02

Familiarization with programming environment and options/menu of the installed compiler.

03

Draw a Flowchart using MS Word (or any other editor or online tools like Draw.io etc.)

04

Programs using I/O statements and various operators.

(a).WAP to print your name

(b).WAP to perform various arithmetic and logical operators.

(c.)WAP to swap two numbers with and without using third variable

05

Programs using expression evaluation and precedence

(a).WAP using unary and tertiary operators

(b).WAP using post and pre - increment operators

06

Programs using decision making statements and branching statements

(a).WAP to check whether the given number is odd or even

(b).WAP to check whether a given number is Prime or not.

(c).WAP to find the largest among the given three numbers

07

Programs using loop statements

(a).WAP to find the factorial of a given number

(b). WAP to print table of a given number

(c). WAP to to print all prime numbers from 1 to 100

(d). WAP to print Fibonacci series till a given number n

(e). WAP to print different star patterns

08

Programs to demonstrate applications of n dimensional arrays

(a). WAP to print 3 x 3 matrix.

(b). WAP to print the transpose of a 3 x 3 matrix.

(c). WAP to add two matrices.

09

Programs to demonstrate use of string manipulation functions

(a). WAP to find the length of a given string

(b). WAP to concatenate two strings

(c). WAP to check whether the given string/number is palindrome or not

10

Programs to demonstrate parameter passing mechanism

a. Create a user defined function to add two numbers.

b. WAP to implement call by value

c. WAP to implement call by reference

11

Programs to demonstrate recursion

(a). WAP to print the factorial of a given number using recursion.

12

Programs to demonstrate use of pointers

(a). WAP to print the address of variable using pointer

(b). WAP to swap the contents of two variable using pointer.
